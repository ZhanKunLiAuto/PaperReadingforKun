DENSE PREDICTION · DEEP SELF-SUPERVISION · IMAGE–VIDEO TOKENIZATION

V-JEPA 2.1

这不是把 V-JEPA 2 简单放大一倍，而是追问一个更基础的问题：如果训练损失只检查被遮位置，模型为什么要让每个可见 patch 都保留清楚的局部身份？

Lorenzo Mur-Labadia、Matthew Muckley、Amir Bar 等 9 位作者 FAIR at Meta、Universidad de Zaragoza arXiv v3 · 37 页
研究目的

在不放弃 V-JEPA 擅长的全局运动理解和未来预测能力的前提下，让冻结视频编码器的每个时空 token 都能直接表达对象边界、深度、局部语义和跨帧对应；这样同一底座既能回答“整段视频发生了什么”，也能回答“这个像素附近是什么、离相机多远、下一帧还对应哪里”。

核心结论

第一，V-JEPA 2 的 dense 弱点不是 token 数量不足，而是损失函数允许错误的责任分配。只有 masked token 被评分时，可见 token 最经济的策略可能是汇总全局上下文，而不是保存自己对应 patch 的边界和深度。

第二，单加 context loss 会以全局语义为代价换局部结构。ViT-L 消融中，ADE20K 从 22.2 升到 33.8 mIoU，但 SSv2 从 72.8 降到 62.5；深层自监督才把 SSv2 拉回 72.1，并把 ADE20K 继续推到 38.6。论文真正的配方是“稠密约束 + 分层语义”，不是简单的 all-token loss。

第三，最终 SOTA 是算法与规模共同作用的结果。2B 模型、VisionMix163M、原生图像 / 视频 tokenizer 和高分辨率 cooldown 一起把 NYUv2 做到 0.307 RMSE；同为 1B 时，V-JEPA 2.1 在 SSv2 和 EK100 action anticipation 反而略低于 V-JEPA 2，说明“2.1 全面替代 2”并不准确。

READING OBJECT

“稠密特征”不是更多 token，而是每个 token 都有可定位的含义

DENSE FEATURE（稠密特征）

英译中：在规则空间或时空网格上，每个局部位置都有一个能被下游直接利用的特征向量。

怎么理解：如果汽车轮子、人的轮廓和物体深度在 patch token 中保持局部一致，线性层就能画出边界、回归深度，跨帧余弦相似度也能传播对象掩码。它强调“哪里是什么”，而不只是整段视频的类别。

CONTEXT TOKEN（可见上下文 token）

英译中：没有被 mask、直接进入 x-encoder 的 patch 表征。

怎么理解：原 V-JEPA predictor 会同时输出 context 和 mask 位置的 token，但损失只检查后者。context token 因此可以互相交换并聚合全局信息，只要最终有助于猜出 mask；它们不必保持“我来自画面左下角这个轮子”的局部忠实性。

DEEP SELF-SUPERVISION（深层自监督）

英译中：不只监督网络最后一层，也把同一自监督目标施加到多个中间层。

怎么理解：论文取三个中间 block 加最终层，将它们拼接并用 MLP 融合，predictor 为四个层级分别输出目标。这样局部信息不必一路穿过 40 层左右的网络后才在末端接受一次惩罚。

MULTI-MODAL TOKENIZER（多模态 tokenizer）

英译中：图像与视频共享 Transformer，但在进入网络前使用各自适合的 patch embedding。

怎么理解：视频用 16×16×2 的 3D 卷积，图像用 16×16 的 2D 卷积，并加入 modality embedding。V-JEPA 2 把一张图复制成 16 帧静态视频；2.1 不再支付这笔计算，也不再给静态图像强加“零运动视频”的偏置。

FAILURE CHAIN

为什么只监督 masked token，会让可见 token 失去局部结构

直接监督为什么又会伤害分类

若对 context token 施加过强、统一的自拷贝约束，最简单的解可能是保留当前局部特征，而减少跨 patch 聚合；这对边界和深度有利，却可能削弱动作识别需要的全局组合。固定 λ 从 0.05 增大到 1.0 时，ADE20K 先升后降，SSv2 则持续从 71.0 掉到 51.1，说明监督强度本身是一条局部—全局取舍轴。

因此 2.1 的真正问题不是“要不要监督 context”，而是“监督哪些、何时监督、在哪些层监督”

距离 mask 近的 context token 对局部连续性最关键，因此得到更大权重；λ 在训练中逐步 warm up，避免网络一开始就走向拷贝捷径；多个中间层同时受监督，让局部结构能沿深度传播，同时由多层 predictor 恢复语义聚合能力。

MECHANISM CHAIN

稠密预测只是一半，另一半是把它送到中间层

公式拆解 · 每个可见 token 怎样重新获得局部责任
Ldense = Lpredict + Lctx,   Lctx = (1/|C|) Σi∈C λi ‖Pφ(Eθ(x), Δy)i − sg(Eθ̄(y)i)‖1

这组公式回答：除了恢复被遮位置，如何要求每个可见位置也对齐完整视图中相同位置的目标表征。

M / C
M 是 masked token 索引集合，C 是可见 context token 索引集合；两者共同覆盖输入位置。
Lpredict
原 V-JEPA 目标，只在 M 上评分，保留从上下文预测缺失内容的训练压力。
Lctx
新目标，在 C 上逐位置对齐 online predictor 与 EMA target；越小代表本地表征越一致。
λi
每个 context patch 的权重，不是所有位置使用同一强度。
stop-gradient
目标分支不接收当前反向梯度，仍用 EMA 避免两支网络一起追逐捷径。
直觉读法：原目标只问“空白处猜得对不对”；新目标再问“你看到的每块内容，是否仍记得自己是谁、在哪里”。两种损失相加，才同时保留预测性与局部锚定。
公式拆解 · 为什么离 mask 越近，context 监督越重
λi = λ / √dmin(i, M)

这条公式回答：有限的 context 约束应优先放到哪些可见 patch 上。

dmin(i, M)
context token i 到最近 masked block 的时空距离；距离按 block 数计算。
1/√d
距离越近权重越大，但用平方根让衰减不过分陡峭。
λ
全局强度；论文选择 0.5，并在 epoch 50–100 逐步 warm up。
直觉读法：mask 边界附近最需要上下文与缺失区域保持连续，远处 token 仍可承担更多全局汇总职责。这个空间权重把“局部准确”和“全局聚合”从二选一改成连续分配。

数据与规模不是附属细节，而是最终模型的重要组成

VisionMix163M 用 LVD-142M 取代 1M ImageNet 图像，并组合约 19M 视频样本；全局 batch 分成 128 个 16 帧视频和 2,304 张图像。主训练 135K iteration，随后 12K cooldown：视频从 16 帧 256² 升到 64 帧 384²，图像从 256² 升到 512²。模型从 ViT-L 300M 扩到 ViT-G 2B，最终再蒸馏出 ViT-L 300M 与 ViT-B 80M。

TECHNICAL DEBT & BOUNDARIES

这篇论文修复了一个真实缺口，也把新的取舍暴露得更清楚

第一，最终 V-JEPA 2 与 2.1 不是单变量比较

两代最终模型同时改变了损失、数据分布、图像 tokenizer、模型规模和 cooldown 分辨率。论文提供 ViT-L 逐步消融来拆解这些因素，这是优点；但最终 0.307、47.9、7.71 等结果仍属于整套系统配方，不能只挂在 context loss 名下。

第二，同为 1B 时，全局和预测任务并非全面提升

1B V-JEPA 2.1 在 SSv2 为 76.9，低于 V-JEPA 2 的 77.3；EK100 action anticipation 是 38.4 对 39.7；K400 / IN1K 也各低 0.3 点。2B 后才超过前作。这可能是局部—全局取舍，也可能是新数据 / 配方差异；现有实验不能唯一归因。

第三，dense benchmark 的“冻结骨干”不等于完全相同读出

深度与分割用线性 projection，证据较干净；Ego4D STA 使用四层 attentive probe、时序池化、多尺度重排和 Faster R-CNN 扩展头；机器人与导航又训练新的 world model。它们证明特征可被任务头利用，不证明编码器本身直接输出框、深度或动作。

第四，机器人 20% 提升含规划器设置变化

60%→70% 是相同 CEM 设置下的表示替换；70%→80% 则同时改成 horizon 8 与不同采样 / 迭代数。第三行更像“新表征支持更长规划设置”的联合收益。每行只有 10 个任务，单次成功就对应 10 个百分点，不能把差值看成高精度估计。

第五，导航是任务后训练，不是拿预训练编码器直接零样本行走

论文在 V-JEPA 2.1 表征上训练 Conditional Diffusion Transformer，并在四个导航数据集做 open-loop 规划评测。10.6 秒对 NWM 的 103.2 秒、平均 ATE 2.990 对 3.032 很有价值，但它证明的是 latent 选择让规划器更快，不是无需导航数据。

第六，VideoQA 并没有统一受益于更细的局部信息

用过滤后的同一 PerceptionLM 数据重训时，V-JEPA 2.1 的平均分只从 57.8 到 57.9；PerceptionTest、MVP、MVBench 上升，TemporalBench 与 TOMATO 下降。更长 64 帧输入、18% 数据过滤和新增对齐阶段也让它无法成为纯编码器替换实验。

第七，数据分布仍决定哪些局部结构最难

V-JEPA 2.1 在 NYUv2 领先，但在 ADE20K、Cityscapes、VOS 与 KITTI 上仍落后 DINOv3。论文推测 VisionMix 中拥挤、多尺度场景不足；这提醒我们，损失能要求 token 保留局部信息，却不能凭空提供训练分布里很少出现的细粒度组合。

第八，蒸馏接近教师但没有免费午餐

蒸馏 ViT-L 300M 在 SSv2 达 76.5、ADE20K 46.7、NYUv2 0.336，明显优于从头训练同规模模型；但教师本身是 2B，训练阶段仍要承担大模型成本。ViT-B 80M 的 ADE20K 为 42.0、NYUv2 0.408，部署更轻但 dense 能力下降。
