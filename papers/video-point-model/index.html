Video-Point Model

让不同相机预测同一个未来：持续三维点身份的价值

Byungwoo Jeon 等2026-10-20 · arXiv v1

总体判断：VPM 的关键增量，是让视频模型预测“同一个物理点以后在哪里”，而不仅是逐帧恢复深度或生成各自看起来合理的视角。通过多视角共同注意力、持续三维轨迹监督和跨视角对应损失，模型获得更一致的未来视频，并把这类表示扩展到动作生成。同数据、同预算的视频对照及逐帧几何消融支持这一机制；不过几何预测仍是学习近似，依赖标定和监督覆盖，联合多视角生成也相当昂贵。真实机器人表中的“成功率”采用 0/0.5/1 任务评分，不能直接当成严格无碰撞完成比例。[§3–7；表2、5、22、27；附录A.3]

它同时输出未来视频与点轨迹，动作扩展再增加机器人动作 token。点轨迹并不是运行时先算出真实未来再交给视频，而是从生成器的预测特征中读出、在训练时提供额外约束。因而正文的因果主张是“轨迹学习改善共享表示”，而非显式动力学引擎保证所有像素服从三维物理。

预测的是未来对应，而非已知视频跟踪

输入是带相机内外参的多路历史图像或视频、语言指令，以及历史帧上选定的点查询 (时间、相机、像素位置)。输出包括请求视角的未来视频，以及这些点在未来各时刻的三维位置；点坐标统一到首个历史时刻的参考相机系。常规跟踪器看到完整视频后寻找对应，VPM 必须在未来图像尚未发生时预测对应。[§3.1–3.4]

以三视角抓放为例，左相机暂时看不见手，右相机仍能看到，腕部相机又有不同遮挡。若三路分别生成，手可能在不同画面到达不同位置。持续点轨迹把它们绑定到同一个手表面点的运动：每个视角的二维位置和深度都应能还原成一致的三维变化。这里“4D”是三维空间随时间变化，不是四维空间坐标。

基础架构来自 Cosmos3-Nano 的 reasoner 与 generator 两塔。reasoner 处理指令，因果注意力限制在自己序列；generator 读取两塔信息。reasoner 在全部训练阶段冻结，主要学习发生在生成通路、相机条件和轨迹头。这一点解释了为何语言能力主要由预训练提供，不能把控制收益全部归因于新训练出的语言推理。[附录A.1]

多视角拼接与逐帧深度为何还不够

图像级训练可以让每一帧逼真，但不会明确告诉模型某个局部外观必须与另一相机、另一时间的同一点对应。逐帧深度或 pointmap 保留几何位置，却可以失去点的身份：每一帧都近似正确，并不等于物体运动连续。作者把“几何结构”与“持续运动身份”分开做消融，避免仅凭加了三维损失就认定收益来自时间一致性。[表22]

三维位置不能脱离相机解释，故模型还需知道每个 token 对应哪条观察射线；多路相机也不能在相同时间和图像网格位置上使用完全相同的位置编码。VPM 因此同时改造相机几何、视角身份和监督方式。这是建立在预训练生成器之上的表示与训练设计，不是从零训练的新视频基础模型。

相机、轨迹与动作如何接入同一生成器

相机射线与第四个位置轴

全部相机的视频 token 被装入共享序列。每个 token 的 Plücker 射线 r=(d,o×d) 编码参考系中的射线方向 d 和原点 o；轻量编码器把它加入特征，并产生 attention query/key 的旋转相位。另将 RoPE 的时间、高、宽三个轴扩为加上 view 的四轴；新视角频率初始化为零，以便从原有三轴模型平稳开始。前者表达真实几何，后者区分相机流身份，作用不同。[式2–3]

从预测特征读出点的位置、深度和可信度

轨迹头读取生成器第18层的 query/key 网格，从历史查询点采样源特征，计算它与各视角未来位置邻域的相关性。空间、时间、视角因子化注意力迭代四次，输出二维点 û、深度 d̂ 与置信度 ĉ。用相机内参 K 反投影，再用旋转 R 和位移 b 转到参考系：P̂=R[d̂K⁻¹(û,1)]+b。未来特征来自部分去噪的 token，而不是未来真值图像；这避免把事后跟踪误当成预测。[式4；附录A.1]

轨迹损失包含二维位置及帧间位移的截断 Huber、log-depth 误差和置信度二分类，跨迭代累积并按可见点平均。另一个对应损失直接把 query-key attention 在正确对应格点上的概率提高。所有二维和深度目标由同一组三维轨迹投影，保持监督的一致性；对应损失不是在声称注意力天然就是物理因果关系。[式5–6]

切换训练阶段与动作扩展，观察哪些模块接收监督以及推理输出如何增加。根据 §3.5、§5；箭头为数据流或注明的监督通路，非性能模拟。

三阶段训练与输入条件的细节

先以视频 flow matching 适配相机与生成器；再冻结主体，以轨迹损失预热头和视角频率；最后用 Lforecast=LFM+λtrackLtrack+λcorrLcorr 联合训练。机器人扩展加动作流匹配损失，未来动作与视频从各自噪声开始共同去噪。训练共使用约 600K 样本，论文新建的 VPM-Data 只有其中 10K，不能把整个训练规模缩写成“仅1万段”。其余包括机器人和公开视频来源。[附录A–B，表7–8]

模型接口可接受请求未来相机的参数，但主评测不给任何方法未来相机轨迹，以免腕部相机未来姿态泄露动作。已观测相机标定与未来相机条件应分开：前者仍是方法依赖，后者在主表被移除，额外给定它的结果放在附录。[§6.1，附录A.1、E.1]

视频、运动和控制三类证据

同预算对照与更严格的几何消融

VP-WorldBench 分为仿真机器人500段、仿真一般场景500段、真实机器人100段、真实室内100段。VPM(V) 与 VPM(V+T) 训练预算相同；V 表示视频，T 表示轨迹。FVD 衡量生成视频分布距离，越低越好；δ3Davg 是从生成视频经 MVTracker 提取轨迹后，落在深度自适应阈值内的平均比例，越高越好，不能与轨迹头自身误差混用。[表2、附录E.4]

几何头便宜，多视角联合生成不便宜

单GH200、BF16、batch=1、35步去噪、480p每视角64帧且含VAE解码时，四视角 Cosmos3-Nano 独立生成63.5秒；VPM(V)101.4秒，V+T102.3秒，V+T+A102.5秒。新增轨迹和动作分别只约0.9秒与0.2秒，但整体联合模型仍约为基线的1.61倍。这是整段视频合成设置，不能当机器人部署每次控制调用时延，更不能由“头开销很小”推出端到端实时。[表27]

可靠的启发与尚未覆盖的世界

几何监督覆盖有限。点主要覆盖机器人和被标注物体，骨架绑定也不刻画衣服、头发独立运动；跨视角持续身份减少不一致，但没有守恒或接触动力学硬约束。作者提出这一覆盖限制，不能把全场景物理可信度等同于若干表面点更准。

主表展示一致性收益，不是闭环安全证明。图像指标、跟踪指标、任务评分分别测不同对象；真机只三个抓放任务且含部分完成分数。要支持安全操作，应增加严格无碰撞成功率、接触失败类别和多随机种子区间，保持物体和视角变化分开，明确是否来自模型误预测、标定偏差或动作执行误差。

训练数据与标定限制迁移。600K混合数据与已标定相机为表现提供了重要条件。更实际的问题是标定有误、动态相机缺姿态、点标签有偏时收益是否保留。建议先测可控标定扰动和轨迹标签噪声，再考虑扩大模型，而不是把本结果外推为无需几何先验的通用世界模型。

最值得采用的是把监督从“每帧是什么样”推进到“同一实体怎样随时间变化”，再同时评估预测与行为。这为跨摄像头驾驶和操作都提供研究思路；但驾驶域的真实碰撞预测和闭环决策并未由本文城市视频结果直接验证。
