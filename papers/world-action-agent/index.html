VISUAL ACTION WORKSPACE · ROBOT PILOT · MULTIMODAL SKILLS

World Action Agent

通用视觉语言模型如何在机器人动作发生前检查它，并在动作发生后修正它。

Yehang Zhang、Haojian Huang 等 16 位作者HKUST (GZ) · CUHK · Knowin AIarXiv v1 · 29 页
研究目的

让通用视觉语言模型（VLM）利用已有语义与空间理解，通过基本工具完成机器人操作，减少对专门动作策略训练的依赖。

核心判断：WAA 的贡献在于把操作接口变成可检查、可修改的视觉工作空间：局部视图揭示偏差，虚拟动作接受规划检查，执行后再在同一视图里纠偏。技能库补上操作顺序与验收条件，是最终成绩的重要来源。现有证据支持这套系统在仿真中有效，尚不足以证明真实机器人上的通用可靠性。[§3]

谁负责判断，谁负责运动

Harness 是模型与机器人之间的工具和反馈层。VLM 选择目标、工具参数与执行时机；逆运动学、cuRobo 规划器和控制器负责实现运动。这里的“预演”主要是候选位姿的几何预览与可行性检查，没有训练视频世界模型来预测完整接触动力学。[§3.2]

看见目标，还不足以对准目标

全局相机可能把“碗与盘子对齐”拍成假象，另一方向仍有偏差；直接发出动作又无法提前检查姿态。若每次纠偏都要求模型把像素关系重新换算成精确三维坐标，误差还会继续积累。WAA 将局部观察、候选动作和修正指令绑定在同一套标定视图中。[图2–3]

一次放碗：先检查姿态，再检查结果

看得清：从场景点云生成两个 Contact 接触视图，优化局部可见性、紧凑取景和视角稳定性，并约束其水平投影正交。一面看似对齐，另一面就可能暴露深度方向的偏差；这些是点云渲染视角，无须物理相机跟着夹爪移动。[§3.2]

改得动：把候选夹爪叠在视图中，先检查姿态和规划反馈。Imagination Agent 可在独立上下文中反复平移、旋转候选，物理场景保持不动；计划可行后由主 Agent 提交。接近目标仍可能留有误差，于是从可见碗表面向盘中心画拖拽线，由标定关系换成有界末端位移，再观察决定是否释放。局部拖拽本身是实际动作，不属于虚拟预演。[图3、附录C]

知道何时算完成：技能包含适用条件、操作关系、参考图和结果检查，避免复用旧坐标。例如放碗要对齐碗底、保持支撑，释放后还要再检查。Skill Agent 单独看历史参考图，与当前画面对照；主 Agent 接收完整文字规程及适用性反馈，减少历史图被误当成当前状态的风险。[§3.3、附录A.2]

技能由 LIBERO-90 每任务一条专家轨迹丰富：Learner 提取带来源帧的经验，Editor 对照既有技能修改，Reviewer 独立核验。人类也能通过同一界面示教恢复动作，但主结果的技能库只从 LIBERO-90 学习并在评测前冻结。“只需视频”也有例外：炉灶示例使用视频对齐的专家末端姿态帮助判断旋转方向。[§3.3–4.1、附录A.3]

WAA 使用 Gemini 3.7 Flash，每划分 10 个任务、60 回合，总计 360 回合；上限为 50 主 Agent 轮、50 次物理操作及一小时。Show-Harness 重跑为每划分 30 回合，其余基线引用原论文。演化技能相对文字种子提高 32.3 个百分点；平均比 ASPIRE 高 3.6 点，但 ASPIRE 在两个 Object 划分和 Goal Pos. 更好，不能说每项都领先。[表1、§4.1]

迁移有支持，但范围有限。冻结的 LIBERO 技能将 robosuite 的方块重新堆叠从 60% 提到 100%，覆盖的仅是抬起、堆叠、重新堆叠三类任务，未明确给出该表的评测回合数。改用融合 RGB-D 或 VGGT 点云后，LIBERO-Pro 平均为 71.1% / 68.9%；这些输入仍在仿真采集。单示范炉灶技能成功 10/10，来自五个初态各两次，证明案例可学，不足以代表任意技能的一次示范学习。[表1、3；附录A.3、B]

小模型学的是调用工具。112 条成功轨迹、1,774 次主 Agent 调用微调 Qwen3.5-9B，使未见种子成功率从 1.7% 升到 43.3%。训练使用 LIBERO-Pro，子 Agent 与空间定位仍用 Gemini；这里的域外只指未见种子，不能解读成未见任务或独立 9B 系统。没有单独验证集，使用最后一轮适配器。[图5、附录E]

预演能挡住什么，挡不住什么

可行计划不保证正确接触。附录失败案例中，模型误读双视图而空抓、丢失目标物体身份，或把盘边的偏置放置判成完成。作者将部分问题归于骨干感知，但未通过控制实验排除接口与反馈设计的影响。关键仍是执行后能否核验真实结果。[附录F]

整体有效不等于模块贡献已分离。没有分别移除 Contact 视图、预演和局部拖拽的受控消融，也没有单独拆分技能文本、参考图、独立审核的收益。同骨干比较支持整套接口有效，无法把提升全部归给“想象”或多 Agent。基线预算与试验数不同，论文也未给出误差条。[§4、表1]

真实部署与速度仍待验证。没有真实机器人实验；重建点云仍需标定与机器人基坐标对齐。表2报告每回合约 31 次模型调用、150 秒、0.20 美元，优于 Show-Harness 的 120 次、874 秒、0.50 美元，但不构成实时控制证据。本页判断：最值得借鉴的是让模型看到动作提案及其反馈的接口设计，其价值依赖几何基础设施、技能知识与结果验证共同成立。[表2、§5]
