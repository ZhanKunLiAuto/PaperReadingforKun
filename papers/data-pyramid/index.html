SCALABILITY · ROBOT ALIGNMENT · HETEROGENEOUS DATA RECIPES

Data Pyramid

一篇不再按模型架构，而是按“数据离真实机器人有多近、又能扩到多大”重排具身操作生态的综述；它最重要的价值不是排出高低，而是给混合数据配方一套共同语言。

Yifan Ye 等 29 位作者 北京大学、南洋理工、港科大、新加坡国立、港大等 arXiv v1 · 72 页
研究目的

回答具身基础模型应该用什么数据：将真实机器人、UMI、人类第一/第三视角、仿真与通用数据放进同一比较框架，解释每一层在可扩展性、机器人对齐、质量、多样性、复用性与物理保真度上的收益和债务，并把这些属性连接到 embodied brain、VLA 与 WAM 的训练配方。

核心结论

第一，没有一层数据同时拥有最高规模、最高物理保真和直接可执行动作。金字塔把“数据不够”具体化为不同缺口：真实机器人缺规模，UMI 缺平台动力学，人类视频缺机器人动作，仿真缺真实物理，通用数据缺接触和因果后果。

第二，近年的明确趋势是从单一机器人轨迹走向异质混合。但“数据源越多越好”并未被证明；论文同时指出只用机器人数据的模型也能很强，真正缺少的是 compute-matched、架构匹配、分阶段的数据配方消融。

第三，动作对齐比文件格式统一更难。跨机器人数据即使都存成统一张量，动作维度、物理语义、坐标系、TCP、绝对/增量模式与控制频率仍可能冲突；配方问题最终会落到表示与几何语义。

READING OBJECT

两条主轴决定位置，四个补充维度决定“值不值得用”

SCALABILITY（可扩展性）

英译中：在硬件、人力、复位、安全监督和边际生成成本约束下，数据源能多高效地继续增长。

怎么理解：仿真搭好资产与任务管线后可并行生成；真实机器人每小时都要占硬件、操作员与复位资源。规模也不能只看条数，重复的单技能轨迹未必扩大状态—动作覆盖。

ROBOT ALIGNMENT（机器人对齐）

英译中：观察、表示与监督信号能多直接地服务真实机器人学习和执行。

怎么理解：同平台真实轨迹动作可直接执行；UMI 提供末端轨迹但要 IK/控制器落地；人类视频需重建和 retarget；通用图文只能提供认知先验。

每往下一层，都放松一部分机器人耦合，换取一种新的可扩展性

FROM TAXONOMY TO TRAINING RECIPE

数据层不是直接相加：先决定模型需要什么能力，再解决动作与几何对齐

跨 embodiment 的动作空间有三种主流解法

Embodiment-specific projection 保留各机器人原生动作，由专属 adapter/head 接入共享 backbone；fixed-dimensional padding 统一张量形状但不保证同一维含义一致；semantic action slots 给每一块预先定义臂关节、末端位姿、夹爪或灵巧手语义，并 mask 不适用维度。第三种语义更强，但需要更严格的数据标准化。

几何对齐要写清坐标，而不是只写“6-DoF”

相同末端运动在 robot-base、world、camera 与 wrist frame 中会得到不同数字。论文把 robot-centric、camera-centric、wrist-centric 分开讨论，并强调原点、轴、左右手系、TCP、绝对/增量、旋转表示和物理单位都应成为一等元数据。

综述事实

数据源越来越异质

论文逐模型整理 2023–2026 年 VLA/WAM 配方，显示真实机器人之外，通用、ego、仿真与 UMI 的组合变得常见。

趋势判断

Ego 正从辅助变成预训练底座

越来越多系统把第一视角人类数据作为主要或独立预训练源，但其收益仍依赖动作恢复、retarget 与机器人 post-training。

尚无答案

最优比例与阶段

论文没有也不声称给出 universal recipe；不同 backbone、动作表示、预算与任务可能对应不同最优混合。

怎么使用这篇综述的证据

它最适合做数据审计清单与研究地图：检查项目是否缺触觉、失败、坐标元数据、真实 post-training 或 action-free pretraining。它不适合被引用成“某层数据必然优于另一层”的性能定律，因为表中规模、过滤、任务、模型和指标并不受控。

OPEN PROBLEMS & TAXONOMY BOUNDARIES

金字塔解决了命名问题，真正的工程难题集中在“采什么、怎么采、怎么混”

证据较强

不同数据源提供互补监督

对采集链、模态、动作形式、物理属性与模型用途的系统盘点清楚显示，没有单一层覆盖全部能力。

分类边界

金字塔不是可计算排名

六个维度没有统一量表或权重；UMI、仿真和 ego 的具体系统差异可能大于类别均值。

仍待验证

更多数据源是否总能提升

机器人-only 模型仍可很强；缺少固定 compute、模型与总样本预算下的逐层增减实验。

一，触觉仍是数据金字塔缺失的接触层

RGB-D 能看到几何和运动，却无法直接给出滑移、局部形变、摩擦、握持稳定与力分布。现有触觉数据受传感器型号、格式、覆盖面积和标定限制，还没有像相机数据一样形成跨平台标准。

二，失败不是低质量垃圾，而是恢复监督

成功示范偏置让策略很少看到部署时真正会进入的错误状态。未来数据应记录失败前上下文、发生时刻、原因类别、状态变化、恢复动作与恢复结果，而不是只留二元成功标签。

三，跨层采集需要更轻、更自动、更会挑数据

可穿戴 tracking、手套、EMG、触觉与 force sensing 仍有遮挡、漂移、佩戴、同步和用户负担。真正可扩展的管线还要自动标定，并主动把采集预算分给不确定、稀缺或行为信息量高的区域。

四，跨 embodiment 对齐需要几何语义，不只是统一 schema

未来数据集应把坐标约定、标定参数与控制器模式作为 first-class metadata，并在变换可信时规范到共享 frame。否则同一动作在不同数据集里可能给出相互冲突的数值监督。

五，人类第一视角更适合提供交互先验，不宜冒充精确机器人标签

人手与机器人手在拓扑、自由度、柔顺性、摩擦和力限上不同。更稳妥的分工是：人类视频提供任务意图、affordance、抓取选择、接触序列与长程结构，机器人数据负责落地动作与接触动力学。

六，数据配方需要架构感知、阶段感知和预算感知

固定比例、curriculum 与 adaptive mixture 谁更好仍没有系统结论。同一数据源对 VLM、VLA、扩散 WAM 或自回归 WAM 的价值可能不同；未来实验应固定训练 compute 与总数据预算，报告每一层的边际收益。

综述本身也有时间与分类局限

论文是 2026-07-27 的 v1，覆盖快速变化的 2026 年模型和部分尚待独立核验的大规模报告；72 页附录式资料非常广，但类别内异质性、数据许可、隐私、去重、泄漏与可访问性没有被同等深入量化。它是一张高价值地图，不是封闭定论。
