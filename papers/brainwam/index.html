SEMANTIC PRIORS · PREDICTIVE DYNAMICS · ACTION-SPACE COORDINATION

BrainWAM

它没有继续把 VLM、视频生成模型和动作 token 全部塞进同一个注意力池，而是先让语义与动力学各自形成驾驶动作，再通过一个紧凑的动作接口交流。

Bing Zhan、Shuyao Shang、Shuo Lu 等 9 位作者 中国科学院自动化研究所、理想汽车 arXiv v2 · 13 页
研究目的

让端到端驾驶规划同时利用 VLA 的交通规则、导航意图与场景语义，以及 WAM 的未来运动、交互后果与物理可行性；关键瓶颈不是缺少模态，而是干净、易学的语义 token 会在共享注意力中压制仍在去噪的视频动力学 token。

核心结论

第一，全文最有诊断价值的是负结果。相同大骨干下，Tri-MoT 只有 87.8 PDMS，反而低于 WAM-only 的 88.1；Fig. 2 同时显示 action token 在多数层更偏向 VLM token，支持“语义捷径压制预测动力学”的解释。

第二，BrainWAM 的贡献是架构分工，不是神经科学验证。真正起作用的组件是专业化分支、动作瓶颈、双向 cross-attention、零初始化残差门和晚期 Transformer 融合；左右脑、胼胝体与小脑只是命名隐喻。

第三，89.5/89.6 是 benchmark SOTA，却不是道路部署结论。两项领先幅度分别只有 0.4 和 0.9 分，论文没有多种子方差；评估仍是 NAVSIM 的短时 non-reactive simulation，而最高分配置单帧延迟约 565 ms。

READING OBJECT

三个概念：模态竞争、动作瓶颈与异步整流流

ATTENTION-ALLOCATION MISMATCH（注意力分配失衡）

英译中：多种模态虽然进入同一注意力空间，但动作查询并未公平使用它们，而是偏向更稳定、更容易优化的语义 token。

怎么理解：VLM token 已被大规模预训练压成紧凑语义；VGM token 却随视频去噪不断变化。前者像一条清晰近路，后者像仍在施工的动态地图。共享注意力并不会自动学会“各取所长”。

ACTION-SPACE BOTTLENECK（动作空间瓶颈）

英译中：两条大模型通路不直接交换全部视觉或语言特征，只交换与未来轨迹相关的紧凑 action tokens。

怎么理解：它既是共同语言，也是信息过滤器。语义通路只能传“对驾驶动作有什么影响”，预测通路也只能传“未来动力学怎样改变动作”；大量与当前轨迹无关的异质细节被挡在接口外。

ASYNCHRONOUS RECTIFIED-FLOW INFERENCE（异步整流流推理）

英译中：视频和动作沿各自 flow timestep 去噪，视频可提前停止并缓存特征，动作继续细化。

怎么理解：规划不一定需要一段高保真未来电影。实验显示第一步视频去噪已恢复大部分规划得分；随后继续生成视频的收益很小，因而可以先拿到粗动态上下文，再把算力留给动作。

WHY RAW-TOKEN FUSION FAILS

更多输入为何会更差：从干净语义到动力学失声

去掉视频去噪后的断崖，证明“动力学无用”不是答案

视频去噪步数为 0 时，PDMS 只有 79.3；增加到 1 步即回到 89.3。也就是说，VGM 通路包含强规划信号。Tri-MoT 的问题更准确地说是信息没有被稳定取用，而不是视频预测与规划无关。

MECHANISM CHAIN

两条通路先各自回答，再由 CAB 交流、CIF 定案

公式拆解 · 视频与动作怎样共享直线路径
xt = (1 − t)x0 + tε,   u = ε − x0

这组公式回答：怎样把干净未来视频或真值轨迹变成可由少步向量场恢复的带噪状态。

x0
干净样本；在视频流中是未来视频 latent，在动作流中是 8 个真值 waypoint。
ε
标准高斯噪声；t=1 时只剩噪声，推理从这里反向积分。
tv, ta
视频与动作各自的 flow 时间。独立设置让视频可提前停止、动作继续去噪。
u
直线插值的目标速度场。模型最小化的是 ||û−u||² 预测误差；u 本身的幅值没有“越小越好”的含义。
直觉读法：两条流不必同时跑到终点。只要粗未来已经给出规划相关的方向，视频流可以停下，缓存特征继续服务动作流。
公式拆解 · 两条动作流怎样安全交换消息
Ãxl = Axl + tanh(gxl) ⊙ Attn(Axl, Ayl)

这条公式回答：怎样让当前通路读取另一通路，又不在训练开始时破坏两个已经收敛的专家。

Axl
第 l 层待更新的 action tokens，作为 cross-attention 的 Query。
Ayl
另一通路的 action tokens，作为 Key/Value；两个方向各算一次。
gxl
1024 维可学习门，零初始化；经 tanh 后逐通道控制跨流残差。
⊙
逐元素乘法。门可以选择哪些动作维度值得共享，而非整体全开或全关。
直觉读法：CAB 刚接上时等价于一根关闭的旁路，不动原模型；训练只需逐渐打开有用通道。附录中冻结两个大分支得到 89.5，优于全量微调的 88.8。

三阶段训练是在保护两种已经形成的专业能力

Stage 1 单独训练 WAM 的视频与动作向量场；Stage 2 单独训练 VLA 的语义动作向量场；Stage 3 冻结两条大分支，只训练 CAB、CIF 与最终 decoder。两个分支在 Stage 3 共享同一个带噪轨迹和同一动作时间步，避免协调层面对噪声等级错位的表示。

仍待验证

闭环真实道路安全

NAVSIM 是短时 non-reactive simulation；没有真实车辆、跨城市或交互闭环实验。

第一，实时性仍远离严格车载要求

系统同时运行 5B 视频生成骨干与 4B VLM，最低 382 ms 是几乎不使用视频预测的低分配置；较好的 1–3 步配置为 475–644 ms。论文也把视频分支蒸馏、双通路去冗余、特征复用和 early exit 列为后续工作。

第二，0.4/0.9 分领先缺少不确定性

论文没有多随机种子、标准差或显著性检验；主表还汇总了来自不同工作的已报告结果。最可信的机制证据是相同骨干、相同数据流程下的内部 ablation，而不是“榜单第一”本身。

第三，注意力权重只能支持解释，不能完成因果证明

Fig. 2 显示多数层的 VLM/VGM attention ratio 大于 1，但没有精确数表、误差条或改变注意力分配的干预。不同 early-fusion 设计仍可能缓解模态竞争；论文证明的是其 Tri-MoT 方案失败，不是原始特征永远不可融合。

第四，“世界模型”没有单独接受世界质量评估

实验只用规划分数证明未来视频特征有用，没有报告生成视频的 FVD、校准、反事实正确性或交通参与者长期一致性。因此更稳妥的结论是“视频预测提供了规划上下文”，而不是“系统已学会完整、因果正确的交通世界”。

第五，复现信息仍有缺口

论文未给完整训练样本规模、split、seed、总参数量、FLOPs、峰值显存、车规硬件延迟以及 WAM 动作损失权重。当前也没有在 arXiv 记录中链接官方代码仓库。
