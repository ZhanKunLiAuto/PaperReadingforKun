ACTION SUFFICIENCY · DIRECT PREDICTION · FUTURE-TO-ACTION CASCADE

DirectWAM

未来预测应保留什么，才能让机器人行动？

Shaoyi Zheng、Zhongtao Jiang 等 7 位作者ByteDance · NYU2026-10-20 · arXiv v1 · 20 页

总体判断：这篇论文最有价值的地方，是把单步 WAM 的训练标准落到“这个预测未来会让动作模型做出什么”上。它保留显式未来表征和未来到动作的级联，将两个扩散预训练专家转换为确定性的单步预测器；通过冻结动作模型的目标对照、局部敏感方向替换和真实机器人实验，较有力地支持了“动作误差应直接指导未来预测”的设计。现有证据主要支持 LingBot-VA 这一骨干上的高效转换：模型延迟从 5,042 ms 降到 180 ms，但 RoboTwin 平均成功率仍从 90.7% 降至 85.4%。它没有证明所有机器人任务都不需要随机性，也没有证明预测未来已成为通用、物理可靠的世界模拟器。[§3.3–4，表2、7–9]

理解全文时应抓住一个具体改动：原来动作专家在真实未来条件下学动作；现在先学好单步动作专家，再把学生自己预测的未来送进去，让动作错误反过来修正未来模型。单步不是直接截断扩散次数，而是重新学习从条件到最终输出的映射。局部 Jacobian 投影是验证该思路的诊断工具，不是部署模块，也不是训练时必须计算的损失。

研究问题

在每条流只能前向一次的预算下，如何保留对动作有用的未来信息，同时避免花费大量计算复现完整的扩散采样过程？

仍然先预测未来，再根据未来决定动作

这里的 WAM 是世界—动作模型。本文研究其中的级联结构：视频专家先预测未来视觉表征，动作专家再结合当前上下文，把这一未来翻译成机器人动作。动作专家可理解为逆动力学模型（IDM）：给定现在和目标未来，推断应采取什么动作。它与“给定动作，预测下一状态”的前向动力学方向相反。

图1中，上下文 h 包括视觉历史、过去动作和指令。未来预测器 F 输出一个未来潜变量块 ẑ；潜变量是视频编码器中的压缩表示，可以解码为可查看的图像，但动作通路读取的是该表示。动作预测器 G 同时读取 ẑ 和 h，输出长度为 K 的动作块。执行后获得新的真实观测，继续下一轮预测。因此它保留在线未来条件化，而不是只在训练时加一个视频辅助任务。[图1、式2]

以论文的“放茶壶”任务作直观理解：未来预测应给动作模型提供足以完成放置的关系，例如物体与目标位置如何对应。背景颜色即便有较大变化，也未必改变应执行的动作；一个较小的相对位置偏差却可能改变落点。这只是帮助理解的例子，论文没有把潜变量中的某几维直接标注为“茶壶位置”或“背景”。它通过动作误差自动学习哪些预测差异重要。

“Action-sufficient”是相对于当前动作模型和数据定义的。若某个未来表征通过 G 后产生接近示范的动作，它就满足本文的训练标准。这里并没有一个信息论意义上的最小充分统计量证明，也没有证明所有物理状态都被正确恢复。G 还直接接收 h，所以 ẑ 也不是整套策略唯一的信息瓶颈。[§5]

路线如何处理未来与推理与本文的区别
完整 LingBot-VA 教师先迭代预测未来，再迭代生成动作保留扩散预训练能力及多步推理成本。
直接截成 1/1两条流各只跑一步没有重新学好单步映射，控制明显下降。
Flash-WAM对视频和动作采用模态专门的一致性蒸馏，达到 1/1与本文部署预算接近，但学习单步映射的目标不同。
Fast-WAM保留视频协同训练，部署不显式预测未来改变在线接口；本文仍让预测未来参与动作生成。
DirectWAM单步未来 → 单步动作；动作误差监督学生未来保留级联，改变训练标准和部署计算过程。

路线描述来自本文 §1–2；本次未逐行审计这些方法的官方实现，不据此声称已完成独立首创性核验。

采样变化不重要，不代表迭代计算可以直接删除

第一步：单独改变视频噪声，动作究竟变多少？

作者固定上下文和动作侧输入，只重采样视频噪声。RoboTwin 使用 237 个上下文、每个 32 个未来样本；LIBERO 使用 64 个上下文、每个 16 个样本。所有未来都交给同一个冻结的单步动作模型。RoboTwin 中，采样引起的上下文内方差占总方差的比例，在视觉空间为 6.6%，在动作空间为 0.030%；LIBERO 为 1.6% 与 0.25%。这说明所测读出模型把多数视频采样变化压小了，但相关系数仍分别为 0.69 和 0.80，动作并非完全忽略未来。[表1、4，附录A.1]

正文还给出动作距离 / 视频距离比 0.025。不能将它直接解释为“只有 2.5% 的视觉信息传到了动作”。两个空间的坐标尺度和归一化会改变这个比值，附录明确提示了这一点；方差占比和闭环干预才是更有意义的补充证据。离线分析用的也是学得的单步动作头，而非教师原生的多步动作采样器。

第二步：把随机性压掉，闭环是否受损？

在 RoboTwin Clean 的 50 个任务上，每个设置共 500 次试验。教师标准采样成功率 91.6%；三种固定视频噪声的平均为 91.2%；每次将四个未来取平均后输入动作模型为 92.0%。各项配对干预的成功率变化绝对值至多 2.4 个百分点，McNemar 检验 p ≥ 0.12，bootstrap 95% 区间包含零。正确结论是未检测到重采样的系统性收益，不是已经证明严格等效。固定一个正常采样的噪声张量，也不是把输入替换为全零。[附录A.3、表5]

作者还挑选有较强未来分支迹象的 30 个场景—指令组合，各运行 8 次。25 个组合全部成功，4 个成功与失败混合，1 个全部失败；轨迹公共前缀的归一化位置离散度中位数约 2%。这支持“所测视频随机性没有形成显著不同的执行策略”，但不是完整动作分布等价证明，也不能忽视少数场景中结果会改变。附录的多模态检验只在选定的降维空间和 32 个样本下几乎未检出多峰，不等于全局单峰。

第三步：删掉迭代，会发生什么？

图3的步数扫描中，RoboTwin 从完整教师的 91.6% 降到 2/2 的 87.4%，再降到 1/1 的 57.6%；LIBERO-Long 对应 98.2%、97.6%、88.6%。随机性可以固定，而多步计算中形成的精细映射仍然有用。因此必须把这个映射重新学成单步函数。随机输入的必要性，与迭代计算的必要性，是两个独立问题。[§3.2、图3a]

只学习视觉匹配仍不够。作者固定模型初始化、数据、优化预算和单步动作专家，只改变未来学习目标：匹配教师未来得到 76.0%，匹配真实未来得到 78.2%。它们明显优于直接截断，但仍留下控制差距。这推动作者进一步问：视觉误差中的每一个方向，是否真的同样影响动作？

数字口径提醒：图3等辅助评估使用每任务 10 次；表2主结果使用每任务 50 次，并报告 Clean / Rand. 及其平均。因此 91.6% 与 90.7%、57.6% 与 54.9% 不应混在同一条主表提升计算里。

先固定一个会读未来的动作模型，再让它教未来模型

阶段一：把动作专家改成直接回归

两条流从已发布、已后训练的 LingBot-VA checkpoint 初始化。第一阶段冻结视频通路，用示范未来 z* 和上下文 h 作为条件训练动作专家 Gψ，直接最小化最终预测动作与示范动作 a* 的均方误差。它沿用教师强制（teacher forcing）的条件接口：训练时提供正确未来，而非让 G 先适应尚未学好的学生未来。训练后得到一个单次前向就能读出动作块的 G。[§3.3]

阶段二：冻结动作专家，用自己的预测承担动作后果

随后 Fθ 从 h 生成自己的未来 ẑ = Fθ(h)，把 ẑ 交给冻结的 Gψ。若产生的动作与示范不符，误差穿过 G 对未来输入的导数，更新 F。这里“端到端”描述的是从动作损失到未来模型的梯度路径；G 的参数不更新，但其输入导数仍然参与反向传播。如果把整个 G 的前向都放进阻断梯度的环境，就无法实现这条学习链。

这一设计同时改变了训练输入分布和优化标准：未来模型必须在自己的输出上接受动作检验，而不能仅依靠真实未来条件下动作模型表现好；未来好坏也不再只由视觉距离决定。仍应注意，训练上下文本身来自示范数据，本文没有用在线环境回报训练 F，也没有证明消除了整条闭环轨迹的分布偏移。文中“从自己的未来在线解码动作”应理解为训练前向内即时计算，而不是机器人一边部署一边自我学习。

“蒸馏”在这里是广义模型转换：继承扩散预训练权重，把最终映射学为单步函数；主要动作监督来自真实示范。它不要求学生拟合完整去噪轨迹，也不是把教师动作输出当成唯一标签。图1保留固定的视频和动作噪声输入，所以“确定性”指无部署时的随机重采样，不必理解成网络接口中已删除一切噪声张量。

附录B给出的 LIBERO-Long 配方是：第一阶段 600 步、有效 batch 16；第二阶段 400 步、有效 batch 8、λv = 0，两阶段约 21 分钟。RoboTwin 则为 8,000 步（约 3.5 小时）加 6,500 步（约 6 小时），学习率均为 10−5，第二阶段 λv = 0.01。训练使用 FSDP、每 GPU batch 1、AdamW，β = (0.9, 0.95)，weight decay 0.1。这里是已有后训练 checkpoint 的转换代价，不包含从零预训练成本；附录也没有给出足够完整的所有套件训练资源配置。[附录B、C.1]

为什么同样大小的视觉误差，会造成不同动作误差？

在一个固定上下文和预测点附近，可以把动作模型局部线性化：δa ≈ Jδz，其中 J = ∂G/∂z。视觉匹配看的是 ‖δz‖²，而局部动作误差看的是 δzᵀJᵀJδz。若某个方向经过 J 会被放大，那个方向上的小偏差就可能非常重要。动作损失反传相当于让 F 感受到这种不均匀的代价；这是一种解释，不表示实际网络是全局线性函数。

交互 2｜保持误差大小不变，只转动方向。二维玩具模型 J = diag(10, 1)，δz = (cos α, sin α)。横轴方向对动作更敏感；不对应真实潜变量维度，也不预测机器人成功率。

论文进一步用 32 个动作输出方向 u，将 Jᵀu 映回未来空间，再正交化成 Q，构造 P = QQᵀ。对一个预测差异 Δz，可以只加回 PΔz，或只加回 (I−P)Δz，观察动作误差和闭环表现如何变化。P 是当前上下文、当前预测点附近、至多秩 32 的探针；它既不保证覆盖所有动作敏感方向，也不必等于 J 的主奇异向量空间。训练目标没有显式限制 F 只能改变 P 内的分量。[附录C.2–C.3]

28 倍是模型侧延迟，不是整套机器人快 28 倍

完整教师模型延迟 5,042 ms，DirectWAM 为 180 ms，比例约 28.0。论文用同种 80 GB GPU，在单卡上预热 500 次后计时 500 次，报告中位数；给出了标称计算规格，但没有直接写明 GPU 型号。180 ms 的倒数约为 5.6 次模型调用 / 秒，这是本页计算，不是作者报告的机器人伺服频率。动作块执行、相机采集、传输和机器人控制周期的总延迟没有被完整拆解，不能将该数字当成端到端控制时延。[§4.1–4.2、图4]

同图 Flash-WAM 约为 26.0 倍加速，说明 DirectWAM 相对它的主要改善是相近速度下控制更好。图中 Fast-WAM 0/1 更快但成功率较低，Faster-WAM 成功率较高但更慢；这些在线接口不同，属于经验效率前沿的背景比较。DIDO 因没有可做匹配计时的公开 checkpoint 未纳入，不能把“在已测配置上处于 Pareto 前沿”改写成所有 WAM 的全局最优。

最有解释力的实验：固定动作模型，只替换未来的局部分量

第一组针对教师差异。令 Δz = zT − zB，即完整教师未来与较弱预测的差异。图3b中，视觉监督学生的敏感分量仅占差异能量 0.85%，却恢复了教师可提供的离线动作误差改进的 34.0%；占 99.15% 的补空间恢复 24.8%。这里的分母是“换成教师未来能减少多少误差”，不是总动作误差；34% 也不是成功率提升。附录C.3加入第四种预测器后范围为 0.31–0.85% 能量、16.3–34.0% 恢复，而图3的三种展示是 0.63–0.85% 与 19.8–34.0%。

第二组针对学出来的差异。令 zV 为视觉监督学生未来，zA 为 DirectWAM 未来，固定同一个 G，只替换 zV 中来自 zA − zV 的分量。离线 64 个 RoboTwin 上下文中，完整替换把动作 L2 距离从 0.257 降至 0.216；只替换 1.9% 的差异能量，误差已降到 0.224，恢复约 80% 的改进。同范数随机子空间和高斯扰动仅恢复 1–2%，说明收益依赖方向，而不只是加了一个相同大小的扰动。[表7]

表8使证据从离线动作误差进一步走到闭环控制：局部修正几乎恢复全部收益。不过 87.3% 与 87.0% 之差没有给出足够统计依据，不能据此认定局部版本优于完整 DirectWAM。它还需要同时获得两个预测及 Jacobian，所以是机制干预，不是额外提出了一种廉价部署方法。这里恢复的是两个已学模型之间的改进，与第一组“朝教师纠错”的百分比有不同参照。[表8、附录C.2]

这组实验比简单展示相关性更有说服力，因为下游模型保持不变，变化只来自送入的未来。但 P 的构造本就偏向敏感方向，所以重要结果不是“敏感方向更敏感”这个定义，而是沿这些方向迁移实际学得差异，真的降低示范动作误差并改善闭环。补空间仍有收益，且局部探针不完整，因此不能推出其余 98.6% 信息都是噪声，也不能把能量占比当成可删除的 token 或参数比例。

核心结论可信，但它依赖什么仍要说清楚

动作充分性取决于这个 G，而非任意下游控制器

F 是通过固定 G 的梯度优化的，可能学出特别适合该读出模型的表示。已有局部替换和多任务结果支持这一接口内的有效性，却没有证明替换动作头、改变动作空间或迁移机器人后仍保持同样收益。更有针对性的验证是冻结 F 后训练或迁移另一种动作读出器，比较与纯视觉监督表示的适配速度与成功率。G 还读取上下文 h；通过打乱未来、替换成常量或阻断未来条件的对照，可以进一步量化最终模型究竟多依赖预测未来。当前替换实验说明未来有因果影响，但尚未完整回答未来模块是否在所有场景都必要。

确定性单步在这些任务有效，不等于多模态决策不需要采样

随机性实验主要操控视频噪声，动作侧被固定或配对；它回答的是所测级联中视频采样的作用。动作回归采用 MSE，若同一观测对应多条有效但不兼容的轨迹，确定性模型有输出折中动作的潜在风险。现有任务并未证明这种风险普遍发生，也没有专门覆盖强多峰绕障、部分可观测或罕见分支。更好的测试是构造同一上下文下必须保留不同策略的任务，并比较成功率、候选多样性和失败恢复，而不是仅增加普通测试次数。

重建锚点与预训练先验分别贡献多少，仍缺直接消融

LIBERO-Long 的 λv = 0 和 RoboTwin 的 λv = 0.01 说明两个设置都能学，但跨基准比较不能隔离锚点作用。论文没有给出 RoboTwin 上充分的 λv 扫描，以及相同预算下冻结 G 与联合微调 G 的完整对照。训练曲线中动作损失下降、加权重建损失近似平稳，支持两者并非同步改善，却不能推出锚点对优化没有作用。要隔离其贡献，应在同一数据、初始化和预算下，比较无锚点、不同锚点强度，并同时观察控制与可解码性。

总体结果充分，复现细节和统计覆盖仍有缺口

主表评估覆盖较多任务，但未报告训练随机种子之间的方差或主表置信区间；真机每项只有 20 次。相同每流调用数也不是所有方法训练预算、参数量和实现优化完全一致的证明。原文未完整说明 GPU 数量、所有 LIBERO 套件转换配置、动作块长度 K、部署固定噪声的具体选择与逐阶段延迟。本次未确认到官方 DirectWAM 代码或 checkpoint 链接，因而不把论文公式当作已经核验的代码行为。

附录A还披露多模态分析从 256 个上下文中剔除了 19 个历史潜变量与指令错配样本；离线传播统计来自原始存储，多模态检验来自单独审计的子集，二者都出现 237 不能直接视为相同样本。作者也说明标准采样的全局视频随机数未设种子，Avg-4 的教师 checkpoint 通过记录的来源匹配而非保存的哈希核对。这些说明提升了可审查性，同时限制了精确重现噪声实验的能力，不应扩大为对全部控制结果的否定。[附录A.1、A.3–A.4]

最值得迁移的研究思路：当一个预测模块服务于下游决策时，既要检查预测像不像真值，也要让它在自己的输出上接受下游决策检验。DirectWAM 的增量在于把这条原则用于扩散预训练级联的单步转换，并用冻结读出器和局部替换连接起机制与闭环收益。若借鉴到其他机器人或驾驶系统，应重新验证动作头的依赖、多模态行为及未来锚点的作用，不能把这里的 1.4% 当成通用压缩比例。
