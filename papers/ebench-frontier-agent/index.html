EBench · Frontier Agent

推理模型会做机器人任务，离稳定控制还差什么

Yifei Yao 等 · 51 页2026-10-26 · 用户提供的 PDF 版本

这篇报告最值得读的是能力剖面，而不是一个总排名：一个通用前沿模型通过工具接口，已经能理解陌生任务、利用演示并组合行动；但接触精度、长过程稳定性和安全持物，仍不能由更强的语言推理自动补齐。在同一套 510 个模拟 episode 中，GPT-6 Astra 直接控制达到 46.7% 的任务宏平均成功率；接入冻结的 π₀.₅ 或 InternW₀-Δ 后分别为 53.0% 和 56.0%。

混合系统的增益说明，高层视觉推理和低层训练策略具有互补性。然而，报告也清楚显示：能调用策略，不代表能可靠地决定何时委派、何时接管，以及怎样保持接管瞬间的物理状态。尤其是夹爪保持指令、策略历史观测和反馈频率这些接口细节，会让“智能体 + 策略”的组合产生新的失败。

看实验前先分清三个指标

成功率 SR是满足任务完整成功条件的比例。总 SR 对 26 个任务等权平均，不是直接把成功 episode 除以 510：任务中有 24 个各 20 次，另两个各 15 次。过程分数 Score记录任务的部分完成程度，因此可能高分但未成功。token / success把失败尝试的 token 也计入，再按成功数摊销，是一类资源效率指标，不是成功 episode 自己的平均花费。

直接控制系统从多相机 RGB、末端位姿、夹爪宽度、底盘位姿及已过时间得到信息，输出末端、底盘和夹爪目标，经控制器执行。混合系统拥有相同观察模态，同时可以把一段时间的控制权交给已训练策略。它们并没有相同的反馈频率和动作接口；因此比较回答的是“这些完整系统怎样工作”，而不是在其他条件完全相同下只替换一个神经网络。

任务还按移动 / 桌面、精度、长短过程分组，但这些属性高度相关：11 个短过程任务中 10 个涉及移动、8 个属于低精度。某组表现好不能单独归因于“移动推理”或“短期规划”，必须结合具体任务观察。

实验设置决定结论能推广到哪里

环境为 Isaac Sim 中的 ARX Lift2 双臂机器人与 GenManip 任务，26 项任务、468 个场景、510 个固定测试 episode。执行以 30 Hz 物理步推进，每个 episode 有 1,500–5,000 步上限，但剩余预算不展示给智能体。没有深度、标定、真值分割、奖励和显式子目标。每个 episode 重新开始，不携带上次任务记忆。

“无需任务训练”的直接控制也不是没有任务信息。它可以查看每个任务的一条带注释训练演示，通常包含 10–18 个关键帧、顺序、机器人状态和动作；提示中还包含抓取、闭合、轻抬和验证等操作惯例。这些信息与 6,600 条域内示范训练出的低层策略不同，但都应计入系统可获得的知识。

推理时模拟器暂停，token、工具次数和推理时间不设上限。因此这不是实时物理机器人测试。模型可以在两次动作之间花较长时间分析画面，而现实中被举起的物体、运动目标和人不会暂停。论文关于控制风险的统计来自模拟轨迹，不表示实际机器人已发生损伤。

机制：真正困难的是控制权交接

切换直接控制、策略委派与交接失败。混合工具接收固定完整任务指令，模型在文字里描述的临时子目标不会自动传给低层策略。

直接控制

RGB + 机器人状态 + 演示
→
Astra 规划与检查
→
末端 / 底盘 / 夹爪动作块
→
执行后重新观察

模型能利用语义和视觉反馈纠偏，但动作块内部缺乏同等频率的高层反馈。报告中 84% 指令只含一个 waypoint，也仍可能持续较长时间。

委派给冻结策略

Astra 调用 policy tool
→
固定完整任务 + 当前观测
→
π₀.₅：每 30 步重规划 / InternW₀-Δ：每 10 步
→
1–300 物理步后归还控制

策略训练过局部操作，但不能直接接收智能体临时提出的阶段目标。策略工具结束不代表整个任务成功。

接管接口的失败

策略抓住物体
→
归还控制 / 记录夹爪宽度
→
高层只命令另一只手
→
原持物手未维持闭合 → 可能掉落

保持当前测量宽度与继续施加闭合保持不是等价控制语义。论文将这种交接情况与随后的抓取破坏联系起来，但没有通过修复消融证明单一因果。

低层策略承担什么工作

π₀.₅ 每次推断 50 个动作，执行 30 步再重规划。InternW₀-Δ 生成 32 个动作，每 10 步更新，使用初始帧及此前相隔 32 步的观测；推理只生成动作而不生成视频。两者都被冻结。模型调用 policy tool 时设定执行长度，范围 1–300 物理步，之后恢复高层观察与决策。

这种控制切换有状态要求。高层刚操纵过机器人后，InternW₀-Δ 所需的历史有时要用填充帧补齐：作者记录 69,054 次策略推断中有 4,276 次如此处理。这是一种潜在分布变化，不能把混合系统表现下降全部归为高层规划错误。

会委派，不等于按能力委派

两种混合系统都在全部 510 次 episode 中先调用策略，92%–97% 的首次调用发生在最初十分之一进程。策略占据约 66.9% 与 65.4% 的物理执行步。任务层面，策略原本越强，混合系统往往越有收益；但委派时长与策略相对能力的相关性弱且不显著。当前 harness 因而更像固定偏好先试策略，再观察接管，并未证明学会了精确的能力路由。

报告结合官方基准中的独立策略结果比较完整系统；智能体各配置使用配对 episode。直接控制短过程 SR 为 73.2%，长过程只有 27.3%；高精度为 11.3%。混合后高精度分别为 7.5% 和 12.5%，远低于 OpenWAM-α 的 32.5%。所以组合的总体增益主要不能解释为补齐了精细接触能力。

增益来自救回失败，也伴随制造新失败

相对直接控制，π₀.₅ 混合系统救回 91 次原失败，同时新增 59 次失败；InternW₀-Δ 救回 96 次、新增 49 次。按任务宏平均计算对应 +6.3 与 +9.3 个百分点。对 π₀.₅，任务内重采样的 95% 区间为 [+2.0, +10.5]，但重采样任务的区间为 [−2.5, +15.6]，跨过零；InternW₀-Δ 在两种统计口径下均保持正向。前者支持固定任务集的平均增益，却不足以确定随机抽取新任务时仍有同样收益。

增益高度集中：玻璃杯任务从直接控制 20% 升至 85% / 80%，洗碗机从 5% 升至 60% / 75%。逐任务进行配对检验并做 Holm 校正后，也能看到某些任务显著变差。不能把总体上涨解释成每项技能都改善。

语义适应和几何执行可以分离

一条演示让相框任务从 1/20 提升到 13/20，但齿轮任务仍为 3/20：看懂顺序可以纠正粗粒度行为，不会自动解决紧配合装配。另一个新组合指令“先放书签、再把笔放到同一本书上”达到 10/10，而对照策略为 0/10。这是一个有价值的组合能力示例，但只测试一条新组合，不能外推为普遍组合泛化。

失败轨迹揭示什么

直接控制的 273 次失败中，188 次已取得部分进展，229 次最终耗尽物理预算。作者还记录了目标几何判断错误、错误动作累积、双臂开环协调和未验证便报告完成。对持物状态，混合运行中存在 338 / 316 次交接后未维护持物手指令的情况，随后两次调用内的抓取破坏比例为 17% / 19%，高于智能体自身指令后的 6.5% / 9.9%。这是关联证据；需要固定其他因素、修改交接协议再复测，才能量化该机制的因果贡献。

成本下降要限定为 token 口径

平均每个 episode 的智能体 token 从直接控制 3.77M 降到 1.83M / 2.22M；按成功数摊销约从 8.1M 降到 3.5M / 4.0M，减少约 57% / 51%。但混合系统额外执行了策略推断，平均每个 episode 约 45 / 135 次，这些计算不在语言模型 token 中。因此结果支持“高层 token 使用更有效”，不能直接换成相同比例的总硬件成本或端到端时延下降。

边界与可落实的研究方向

这里只有一个前沿模型、一个模拟机器人平台和特定 harness。训练策略见过域内示范，直接控制拿到结构化演示，且推理期间时间冻结；所以结果既不是模型裸能力排名，也不是实机部署证明。移动、精度、任务长度之间的混杂也意味着分组差异应作为诊断线索，而非单变量因果结论。

论文提供一个很有用的事后择优参照：若按任务挑选直接控制或单独策略中更好的那个，宏平均可达 56.2% / 60.8%，实际混合为 53.0% / 56.0%。这提示选择和协调仍有损失。但它不是混合系统的理论上界：合理组合可能在同一任务上超过两个单独系统。

对后续系统最直接的启发，是把接管视为明确协议：谁维护夹爪保持，策略需要怎样的历史，阶段目标能否传递，什么情况必须重新感知，失败怎样回退。还应在相同总时间与计算预算下比较，进行真实物理验证，并针对高精度任务测试更密集的闭环反馈。比继续增加一段推理文字更有希望的，是让这些可测的控制假设在接口中成立。
