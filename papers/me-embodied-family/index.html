COGNITION · MEMORY · WORLD-ACTION · TOUCH

ME 四篇合读

认知、记忆、统一生成与触觉，离可靠的具身系统还有多远？

ME-VLM / ME-Brain-1.0 / ME-U0 / ME-Dex1.0理想汽车 Foundation Model 团队以用户提供的四份 PDF 为准
共同目的

让机器人把任务理解、历史经验、未来状态预测和接触反馈用于实际动作，并在有限计算资源下持续运行。

核心判断 · 本页评价

这套工作的工程整合价值较高，局部能力提升有依据；对“统一后的协同增益”和“部署后持续进化”的证明仍明显不足。它展示了值得继续投入的研究体系，但现有实验尚未把四条路线连成一个经充分验证、长期可靠的系统。最应警惕的，是用若干模块的好成绩替代整套系统主张的验证。

四篇说的“统一”不是同一件事

VLM 统一认知和 Agent 能力；Brain 统一运行时模块；U0 统一理解与生成的训练；Dex 统一异构触觉表示及多模态预测。它们共享“让信息进入行动”的目标，却不能因为都叫统一，就被视为同一个模型或已经打通的流水线。这里讨论的是整套路线协同价值的证据边界，并非说每篇都承诺过四者集成。

共同瓶颈：信息没有变成可靠的下一步

以拿起杯子为例：看懂杯子不等于知道能否抓；记住上次失败不等于下次会改；预测杯子运动不等于预测夹持力；一次抓成功也不等于换杯子、换场景、连续工作一天仍可靠。四篇分别补这些缺口，评价时必须检查每条信息通路是否真的改变了动作结果。

WHAT CHANGED

值得保留的四个技术动作

ME-VLM：先练专长，再把能力合到一个模型

在 Qwen3.5 上进行具身监督微调，分别强化具身专家与 Agent 专家，再让学生在自己生成的轨迹上接受多教师指导。目标是保留物理判断，同时吸收工具、规划和恢复能力；部署时只有学生模型。价值主要在后训练配方与数据整合，MOPD 本身沿用已有范式。［VLM §4，p9–12］

ME-Brain：把一次执行变成可检索、可复用的经验

系统把多模态经历逐层整理为短、中、长期记忆，认知核心据此规划、调用技能和检查结果；动作模型关注事件关键帧与 EventCell 局部未来，并按动作需要读取历史。这里要区分任务内历史有用与跨任务经验积累让系统持续变强：前者有基准支持，后者需要随部署时间变化的对照。系统级短、中、长期记忆与动作专家读取的单条轨迹视觉历史是两个层级；RoboMME 主要验证后者。外部记忆更新也不等于模型参数在线学习。［Brain §4–6］

ME-U0：把任务语义与视觉—动作生成接到一起

理解专家预测子任务和操作位置，生成专家联合生成未来视觉与动作，共享注意力连接两者。多速率位置编码对齐低频视频与高频控制；未来 RGB、深度、法线、光流按提示选择训练，并非每次推理同时生成四种模态。约 4,200 小时筛选数据及跨机器人动作语义对齐，是可见的工程积累。［U0 §3–6，p6–18］

ME-Dex：把触觉从输入条件变成未来预测目标

共同手部模型与触觉自编码器先对齐不同传感布局；视频、触觉、动作三专家再联合去噪，通过中层共享注意力交换信息。仿真重放补充成对的力、图像与动作数据。可辩护的新意在异构触觉表示和系统集成，预测式触觉路线已有先例；原文相关工作也承认 VT-WAM 等方法。［Dex §2–3，p5–12］

CRITICAL ASSESSMENT

最重要的不足：主张与实验之间还缺哪一环

1. “自进化”是最大主张，也是最薄弱的证据链

Brain 的任务内记忆基准、六任务成功率和长程演示，不能隔离长期经验的作用。原文 p30 §9.2 明确把长期运行、环境变化、技能复用的对照与消融列为后续工作。因此当前更有把握的定位是“支持经验更新的系统架构”，而不是已证实会稳定自主进化的机器人。

关键补证应在相同底座、相同交互预算下，对比固定记忆、只检索、允许经验归纳与技能更新，测第 1/10/100 次任务的成功率、恢复成本和旧技能退化；还要测错误经验写入后能否纠正。这比再补一个成功视频更能决定价值。

2. “统一更好”的因果归因不够，四篇的成绩也不能重复计算

VLM 缺原始底座、混合 RL、分支 RL 与蒸馏前后的匹配对照；U0 缺逐项去掉子任务、操作位置、几何监督和多速率编码的实验。无法区分收益来自新机制、更多数据、教师标注还是训练投入。Dex 的消融更扎实，但仍缺等容量、等算力对照。Brain 又复用了 VLM 的认知结果，四篇并不等于四次独立验证。［VLM §6；U0 §7；Dex 表1；Brain §7.1］

3. Dex 最值得追问：触觉到底参与了在线决策，还是主要帮助训练？

同一个完整 Dex 模型，实时触觉置零后，Clean/Random 成功率从 91.56/91.92% 变成 91.70/91.74%，几乎不变。作者也承认该设置对当前触觉不敏感。置零仍保留触觉训练监督和未来预测，所以不能说触觉无用；它说明在线触觉反馈是增益主因尚未被证明。该结论限于 RoboTwin；DexJoCo 为 65.3% 对 DECO.p 的 57.8%，ManiFeel 为 70% 对 55%，但两者未报告对应的置零消融。［Dex 表1、3–4，p13–15］

更有区分力的试验是固定视觉外观，改变摩擦、重量、接触刚度或制造滑移，再交换/延迟触觉信号，观察动作是否相应改变。目前高频触觉反射仍属未来工作，编码器重建精度也不等于未来力预测准确度；真实机器人主要是定性展示。［Dex §4.4–5，p16–18］

4. “跨平台、零样本、泛化”都需要更窄地理解

U0 在 RoboDojo 的随机泛化、记忆、开放任务成功率分别只有 1.33%、7.00%、0.92%。作者指出模型没有显式保存观测历史；真实演示也只使用预训练见过的机器人形态。其子任务和视觉预测的“零样本”主要由可视化支撑，不能替代未见任务的控制成功率。［U0 表3、§7.3–7.4］

Dex 共用触觉编码器后，仍分别训练各基准策略；重建测试来自已参与训练的数据源内轨迹划分，不是留一传感器或留一硬件迁移。VLM 的导航则经过领域数据适配。表示能共用、看起来预测合理、同分布得分高，与新硬件新环境中可直接可靠执行，是不同层级的证据。［Dex §4.1、4.4–5；VLM §3.2、6.3］

5. 模块假设和部署成本没有全部进入评测

Brain 的 EventCell 标识被作为结构条件输入，原文提醒这不应被理解为在线事件检测；事件与局部区域如何在完整部署中产生、出错后如何恢复，需要单独量化。U0 使用远程服务器展示，U0/Dex 的联合生成没有充分报告端到端时延、控制频率和成本。世界模型增加的计算，究竟换来多少任务收益，仍难判断。［Brain p15；U0 §7.3；Dex §5］

6. 统计、汇总口径和复现版本还不够扎实

Dex 本文训练的策略实验只有一个随机种子；U0 的部分基线来自异源报告；Brain 的实机覆盖也有限。小幅增益应与方差、试验规模和训练预算一起解释。VLM 表2 的 72.5 也需澄清：本页复算全部 16 项均值为 67.94，排除工具及两项 ClawEval 后 12 项均值约 72.51；这提示聚合范围差异，原文未明确给出可复算的聚合规则，因此不能把它直接读成覆盖全部 Agent 任务的均分。

截至 2026-09-29，VLM 代码/权重和 Brain 整体框架仍有发布待办；U0 已有后训练评测代码，Dex 已有训练推理入口及权重链接，不能一概说未开源。Dex 当前 README 的 Clean/Random 为 88.9/71.9%，附件为 89.6/68.1%，本页不混用两版；复现需要明确论文、代码、权重和配置的一一对应。［官方仓库；Dex 表2］

我的价值判断：值得投入，但下一阶段应以证明可靠性为中心

工程价值较高：数据治理、多模态训练、记忆与动作接口、端侧优化都在解决实际瓶颈。学术证据中等且不均：Dex 的问题和消融最具体，VLM 最终模型表现强，但训练配方的归因不足，U0 的统一方案覆盖广但机制贡献未拆开，Brain 的系统组织有意义而“持续进化”尚待验证。

如果决定后续投入，我会优先补长期经验的受控收益、触觉的因果干预、固定预算下的统一模型消融，并在同一真实平台报告完整链路延迟、失败恢复和跨日成功率。这些结果才能把一套有潜力的技术组合，提升为有证据支撑的可靠系统。
