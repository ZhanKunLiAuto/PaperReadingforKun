EXECUTABLE WORLD REPRESENTATIONS · ABDUCTIVE DISCOVERY · QUANTITATIVE PHYSICAL REASONING

Code as Worlds

它不满足于生成一段“看起来合理”的未来，而是把物体、参数、初始状态、动力学和相机写成能运行的世界程序，再用执行结果反复检验这个假设。

Hanyang Wang、Yimo Cai、Weiliang Chen 等 17 位作者 MirroS、清华大学、北京大学、南洋理工大学 技术报告 · arXiv v1 · 31 页
研究目的

找到一种既能保存物理组成与动态机制，又能执行、编辑、回放和用观测证据验证的世界表示；随后用验证过的模拟状态自动产生世界尺度的尺寸、位移、速度和加速度监督，弥补真实单目视频缺少定量物理标签的问题。

核心结论

第一，Code-as-World 是一种世界假设语言，而不是新的视频生成 backbone。物理组成 C、动态演化 E、视觉外观 A 被分别编码，编译到 MuJoCo 后可执行、局部编辑和反事实重放。

第二，Agentic discovery 的价值来自闭环诊断。同样五次评估预算下，迭代修改在 Visual Alignment、Object IoU、Traj-ADE 与 Accuracy 上优于独立 Best-of-5；但主文 animation-engine 实验的 Velocity-ADE 例外。

第三，VLM 学到的是发现结果，不是发现过程。Code-as-World-VL 用像素测量数据做 SFT，再用 EWR 产生的世界尺度 QA 做 GRPO；测试 27B 时没有 EWR、模拟器状态、轨迹、工具或检索。

第四，58.6 是公开 QuantiPhy-validation 上的结果。该协议只有 159 个 QA，给定参考物理量，3D 题还提供深度上下文；它证明定量尺度校准显著提升，不等于无先验通用物理推理已经解决。

READING OBJECT

三个概念：可执行世界、溯因发现与物理等价

EXECUTABLE WORLD REPRESENTATION（可执行世界表示，EWR）

英译中：把对象、参数、初始状态、演化规则与相机外观写成满足模拟器接口、能够实际运行的程序。

怎么理解：普通文本说“两个球相撞”，EWR 还要决定球的真实尺寸、质量、摩擦、速度、接触几何、重力、相机和时间轴；运行后必须产生完整状态轨迹。

ABDUCTIVE REASONING（溯因推理）

英译中：从不完整观察出发，提出一个能解释现象的最佳假设，再用新证据反复修正。

怎么理解：文本或单目视频都不足以直接读出质量和摩擦。文本世界主要核对语义关系与物理约束；视频世界还会比较 RGB、深度、mask 与轨迹。误差诊断再告诉 Agent 下一轮该改几何、相机还是动力学。

PHYSICAL EQUIVALENCE（物理等价）

英译中：目标不是逐像素复制输入，而是恢复足以复现关键对象、事件与运动关系的机制结构。

怎么理解：材质、背景和光照可以变化，只要核心碰撞或轨迹保持；但“看起来与证据一致”仍可能对应多组尺度、质量、摩擦与相机组合，因此物理等价不等于因果唯一。

REPRESENTATION GAP

为什么视觉合理、几何完整与语言解释都还不够

单目逆问题没有唯一答案

观察到同一条二维轨迹，既可能来自不同真实尺度与速度，也可能来自不同相机焦距；碰撞后速度相近，也可能由多组质量、摩擦和恢复系数组合产生。Agent 能找到一个解释，却没有从有限证据证明这就是唯一底层机制。

感知误差会被误写成物理参数

视频 adapter 依赖 SAM3 的 mask/track、VGGT-Omega 的深度与相机、SAM3D 的 mesh。任何分割、深度或跟踪偏差都可能进入诊断，最终被 Agent 用错误尺度、位置或动力学补偿。论文没有逐项移除这些证据源的消融。

DISCOVERY AND LEARNING

EWR 先被执行验证，再变成 VLM 的定量老师

公式拆解 · 一个可执行世界包含什么
p = (C, E, A) ∈ Pexec

这条公式回答：什么样的世界描述才不仅能被读懂，还能被编译并运行。

C
Physical Composition：对象、几何、真实尺寸、质量、摩擦、重力与参与接触的环境实体。
E
Dynamic Evolution：初始状态、时变轨迹、关键事件、约束、模拟时长与终止条件。
A
Visual Appearance：相机、背景、材质、灯光、帧率与分辨率；原则上不改变底层物理。
Pexec
满足 simulator SDK 接口的程序空间；语法正确但不能运行的描述不在其中。
直觉读法：把“世界是什么、怎样演化、怎样被看见”分开，才能只改相机而不改物理，或只改初速度而重放同一场景。

Animation engine 与 physics engine 是同一接口的两种执行语义

Animation engine 直接用时变位姿描述“什么在怎样运动”，主文视频重建主要使用它；physics engine 则从力、接触和约束推出运动，附录 Figure 11 再验证迭代收益。前者更易拟合观测轨迹，后者更接近机制推演，不能把两种证据混成同一物理精度。

公式拆解 · 像素运动怎样变成世界单位
γ = ρ / ρpix,   y = γypix

这组公式回答：单目视频没有绝对尺度时，怎样利用题目给定的参考物理量校准尺寸、位移、速度或加速度。

ρ
参考物在世界坐标中的已知真实量，例如球的直径。
ρpix
同一参考量在图像中的像素测量；模型先在 Image-Space 阶段学会定位它。
γ
像素到世界单位的比例尺。透视变化明显的 3D 题还需要 benchmark 提供的深度上下文。
ypix, y
目标像素量与最终世界量。QuantiPhy 主要考查这一校准链，不是无参考尺度恢复。
直觉读法：模型不是凭外观猜“一米有多长”，而是先找到一把题目给定的尺子，再把图像差分测得的运动量按比例换算。
公式拆解 · GRPO 怎样奖励定量回答
rnum = exp(−|ŷ−y|/(|y|+ε)),   r = rnum + λurunit + λfrfmt

这组公式回答：怎样同时约束数值接近、单位正确和输出可解析。

ŷ, y
模型预测值与 EWR 状态提供的精确真值。
rnum
相对误差指数奖励，范围 (0,1]；误差越小越接近 1。
runit
单位奖励，防止“数值对但 m/s 写成 m”仍得高分。
rfmt
格式奖励，保证答案能被 benchmark parser 稳定读取。
直觉读法：可执行世界提供连续真值，奖励不必只做对/错二分；但论文没有公布 λu、λf，完整训练配方仍不可复现。

TECHNICAL DEBT & BOUNDARIES

程序让假设可失败，却没有让物理逆问题变唯一

证据较强

EWR 是有效的物理监督源

两阶段训练在 QuantiPhy 与五项像素测量上同时提升，数据源消融方向一致。

只能有限外推

恢复与证据一致的世界

循环可提高重建指标，但输入经筛选、有人审，且当前主要覆盖刚体运动。

仍待验证

恢复唯一真实机制

多组尺度、相机与物理参数可能产生相近观测；论文没有因果可识别性证明。

第一，模拟器覆盖决定可表达世界

当前重点是刚体、显著运动与碰撞。流体、布料、燃烧、断裂、弹塑性和气体需要新的专用引擎与验证证据；地形、材质、接触几何或隐变量差异也可能让恢复结果只是局部视觉合理。

第二，数据生产仍有人类筛选与未披露成本

文本规范经过人工审核，WISA-80K 候选也筛除相机运动、剪辑、低运动和事件不完整视频。论文未报告最终 EWR 数量、接受/拒绝率、Agent token 成本、墙钟时间或总工具调用；Best-of-5 只匹配评估次数，不一定匹配总预算。

第三，QuantiPhy 范围窄且答案公开

评估使用 159 题公开 validation，主要考查参考尺度下的尺寸、位移、速度和加速度；27B 还在该 validation 协议上报告训练 step 60。没有隐藏测试来验证复杂接触、遮挡、形变、流体或长时多体推理。

第四，VLM 尚未内化 world discovery

发现 Agent 负责假设构造、模拟、诊断与迭代；VLM 只学习这些世界产生的 QA。若任务要求对一段新视频主动提出多个机制、调用模拟器做干预并解释失败，当前 Code-as-World-VL 本身不会执行这套循环。

第五，报告仍有复现与编辑缺口

未披露 discovery agent 所用 LLM、关键帧选择细节、奖励 λu/λf 和 4B/9B 的完整优化配置。除 55.4/56.8 冲突外，附录 B.2 说 physics-engine 结果见 C.1，实际 Figure 11 位于 C.2。

标题页写 “Date: August 31, 2026”，官方 arXiv v1 提交为 2026-08-27。本页目录元数据采用 arXiv 提交日，首屏同时标注 MirroS Technical Report；二者不是同一个发布日期口径。
