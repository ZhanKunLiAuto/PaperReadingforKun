ACTION-ORIENTED WORLD MODEL · CONTINUOUS INTENT · RETRIEVAL PLANNING

Auto-JEPA

它把世界模型的问题从“未来画面会长什么样”改写成“当前场景意味着自车接下来该怎样运动”，再用这个连续意图去检索真实轨迹，而不是让网络直接回归坐标。

Jiwei Yang、Zhengxian Chen、Chaosheng Huang、Jun Li 清华大学车辆与运载学院、智能绿色车辆与交通全国重点实验室 arXiv v1 · 12 页
研究目的

让端到端驾驶模型只压缩那些会改变未来自车动作的场景信息，避免为不相关背景、车辆和纹理付出稠密未来重建成本；同时把预测结果直接变成规划接口，在没有目标框、占据图、周车轨迹标签或学习式轨迹生成器的条件下，输出运动学上可执行的四秒轨迹。

核心结论

第一，Auto-JEPA 是动作导向的潜在世界模型。它不预测周围车辆未来状态，也不生成未来画面；“世界”只通过它对四秒自车运动的影响被保留下来。因此它适合规划，却不能替代仿真或显式多智能体预测。

第二，连续意图并不是离散左转/右转类别。8 个时间对齐 token 共同编码一条具体轨迹的几何、速度和加速度；预测 latent 与 110,335 条真实轨迹 latent 做余弦检索，Top-300 再接受安全与质量筛选。

第三，最有说服力的证据不是 91.3 分本身，而是“去掉意图会崩、动态体遮挡更敏感”。固定意图原型令 PDMS 从 91.3 降到 52.6；全验证集上，动态交通参与者遮挡引起的平均 latent 变化是随机等面积遮挡的 2.97 倍。不过主结果只有单次确定性评测，仍缺多随机种子与真实闭环验证。

READING OBJECT

先分清三个对象：未来意图、轨迹几何与场景质量

CONTINUOUS DRIVING INTENT（连续驾驶意图）

英译中：对一条未来自车运动实现的连续潜在表示。

怎么理解：它不是“保持车道”这种标签，也不是一句语言解释，而是 8×1024 的序列特征。每个 token 对应未来一个时间点，8 个 token 合起来描述 0.5 秒间隔、共四秒的运动。不同速度、曲率和制动强度可以在 latent 中连续变化。

NON-PARAMETRIC TRAJECTORY RETRIEVAL（非参数轨迹检索）

英译中：不训练一个坐标生成器，而是从固定样本库中找最接近预测意图的真实轨迹。

怎么理解：检索提供“画得出来的坐标”，还继承了日志轨迹的运动学合理性；代价是系统永远不能输出记忆和 Top-K 候选都没覆盖的动作。

SCENE-CONDITIONED SELECTION（场景条件选择）

英译中：在意图相似的候选里，结合当前场景重新判断哪条最安全、最有效。

怎么理解：余弦相似度只回答“像不像想做的动作”；CLOVER 初始化的 scorer 回答“放在这个场景里质量如何”；DAC gate 则专门预测驶离可行驶区域的风险。三者不可互相替代。

WHY PREDICT LESS

旧世界模型的矛盾：信息越完整，未必越适合当前规划

动作相关性不是人工标注，而是由未来轨迹目标间接产生

视觉编码器从未接收目标框、动态体类别、周车身份或交互标签。训练信号只要求预测的 latent 靠近未来自车轨迹 latent。若某辆车会迫使自车制动或绕行，它的视觉存在有助于降低 intent loss；若一辆相邻车不影响自车轨迹，保留它对 loss 的帮助很小。这就是论文所谓的 selective focus。

但“只关注相关信息”仍是经验结论，不是可识别性保证

轨迹监督并不能数学上阻止 latent 编码天气、道路风格或数据集捷径；它只让这些信息在没有预测收益时缺少保留动力。语义遮挡实验支持模型确实更依赖动态交通体，但没有互信息约束、反事实因果干预或跨域去捷径实验来证明 latent 只包含行动相关因素。

MECHANISM CHAIN

两阶段训练，四个责任模块：从坐标学出意图，再从场景预测意图

公式拆解 · 连续意图怎样被定义
Z+ = Etraj(Y) ∈ ℝ8×1024,   Ŷ = Dtraj(Z+)

这条公式回答：怎样把 8×2 的未来坐标变成既保留时间结构、又适合作为 JEPA 预测目标和检索键的表示。

Y
8 个二维 waypoint，0.5 秒一个点，覆盖未来四秒；训练前坐标按 64 缩放。
Etraj
4 层 Transformer 轨迹编码器，1024 隐藏维、16 头、8 组 Fourier 频率；预训练后冻结。
Z+
目标意图 latent。8 个 token 对应 8 个未来时间位置，共同表示一条连续运动，而不是 8 个动作类别。
Dtraj
训练期轻量解码器，用坐标、终点、速度与加速度一致性损失验证 latent 能重建轨迹；随后丢弃。
直觉读法：先训练一把“轨迹尺子”。只要视觉预测落在这把尺子的某个位置，就可以到用同一把尺子编码的日志记忆里，找回一条具体、真实出现过的运动轨迹。

三项 joint-embedding loss 各修一类问题

Feature Smooth L1 对齐归一化后的局部特征值；token-wise cosine 逐时间点对齐运动语义；batch InfoNCE 把一条完整 latent 展平后，与同 batch 其他场景拉开，避免所有场景坍缩到相似表示。总损失为 Lintent=0.1Lfeat+2.0Lcos+LNCE，InfoNCE 温度 τ=0.07。

公式拆解 · 意图怎样落成最终轨迹
rn = Norm(vec(Ẑ))⊤ Norm(vec(Zn)),   Y* = Yarg max sk, pDACk≤0.2

这组公式回答：先按 latent 相似性召回哪些轨迹，再在当前场景中允许哪条候选获胜。

rn
预测意图与第 n 条记忆轨迹的扁平余弦相似度；越大越适合作为候选，取前 300 条。
sk
场景条件 scorer 对第 k 条候选的综合质量分，输入当前场景特征、自车上下文与候选轨迹。
pDACk
独立 gate 预测候选违反 drivable area 的概率；大于 0.2 时屏蔽，若全部被屏蔽则恢复未门控排序。
直觉读法：检索负责“别漏掉合适动作”，scorer 负责“在当前场景里挑最好”，gate 负责“把可能驶出可行域的先剔除”。最后两步不能补造候选，因此系统上限仍由意图召回和记忆覆盖决定。

“端到端”指接口，不等于所有模块联合训练

传感器输入直接得到轨迹，过程没有显式感知输出，因而接口上是端到端；但优化是分阶段的：轨迹 AE、intent predictor、scorer 与 DAC gate 分开训练，scorer 和 gate 的梯度不会回到视觉编码器或 JEPA predictor。更准确的描述是“端到端规划接口 + 模块化训练”。

证据链最稳的部分

规划分数、组件消融和遮挡分析指向同一个机制：场景化连续意图承担候选召回的主要责任，scorer 负责从多条相近几何中精排，gate 只做有限的可行域补丁；模型对会改变自车动作的交通参与者表现出更强响应。

TECHNICAL DEBT & BOUNDARIES

这条路线把生成难题变成检索难题，也把上限交给了记忆与校准

证据较强

未来自车 latent 可作为规划接口

同一轨迹编码器连接监督与检索；移除 intent 后性能断崖式下降，说明 latent 不是只在训练期提供辅助正则。

只能有限外推

选择性关注不等于完整因果理解

遮挡实验显示相对敏感度差异，却没有验证对象身份、交互关系和未来反事实是否被正确建模。

仍待验证

真实闭环与分布外记忆覆盖

NAVSIM 是数据驱动、非反应式评测；论文没有证明固定记忆在新城市、极端行为或交互闭环中仍能召回可行动作。

第一，固定轨迹记忆决定可达动作空间

若合适的急刹、绕障或非常规转弯从未进入 110,335 条记忆，预测器、scorer 和 gate 都无法合成它。Top-200 到 Top-300 的饱和说明简单扩大候选数量已接近当前组合的上限；更广记忆、分层索引、条件生成或局部轨迹优化才可能扩展可达集合。

第二，召回之后仍有评分与门控校准问题

scorer 可能把合法候选打低分，gate 可能拒绝边界合法轨迹或放过驶出可行域的轨迹。全部候选被过滤时的 fallback 只保证有输出，不保证安全。论文提出 uncertainty-aware scoring、hard-negative training 等方向，但当前系统没有可证明的安全兜底。

第三，“无需感知标注”不能理解成完全无结构监督

intent predictor 不用对象框、占据或周车轨迹标签，这是事实；但轨迹 AE 需要未来自车 GT，scorer 和 gate 的 75,823 个训练场景使用 NAVSIM/CLOVER 离线 evaluator 生成碰撞、DAC、TTC、舒适度和进度标签。整套系统仍依赖强任务监督，只是没有中间感知标签。

第四，主表不是端到端联合学习的单一收益

视觉编码器冻结，scorer 从公开 CLOVER scorer 初始化后单独适配，gate 也独立训练。因此 91.3 是“V-JEPA 视觉特征 + intent predictor + 固定记忆 + CLOVER 初始化 scorer + gate”的系统结果，不能全部归因于 JEPA 预测目标。

第五，主结果只有一次完整 navtest 运行

论文明确说明所有 benchmark 数字来自选定 checkpoint 的一次确定性全量评测，不是独立重训模型的均值；没有标准差或置信区间。15,364 个遮挡样本提供了稳定的数据内干预统计，但无法替代模型训练随机性的重复实验。

第六，它不是用于显式未来仿真的通用世界模型

Auto-JEPA 不输出其他交通体状态、未来图像或可反事实编辑的环境轨迹。若应用需要交互仿真、长时 rollout 或“如果前车突然加速会怎样”的环境级查询，动作导向 latent 不足以提供答案。论文的有效范围是当前观察到四秒自车轨迹的规划接口。
