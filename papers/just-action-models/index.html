WORLD MODELS · EVIDENCE & MECHANISMS

Just Action Models

未来监督有用，但视觉生成并不是这份收益的唯一来源

Yonghao Yu 等2026-10-27 · arXiv v1

JAM 最重要的贡献，是把“用什么模型初始化”“怎样从未来观测学习”“部署时运行什么”拆成三个可分别检验的问题。结果支持一个很实用的判断：在本文的模仿学习任务里，未来监督有价值，但它不必通过生成图像或视频实现。给当前视觉特征加上预测未来编码的训练目标，就能保留甚至改善匹配 WAM 的控制性能；预测头和未来编码分支随后全部移除。[§3、表1]

最有力的结果来自固定策略架构的对照，而非跨模型排行榜：JAM 在 LIBERO-Plus 上把 FastWAM 的 55.31% 提升到 64.54%，把 ImageWAM 的 65.27% 提升到 79.95%；对应配对任务 bootstrap 的 95% 区间均排除零。与此同时，RoboTwin 的增益很小，且 Wan 在 Randomized 设置略低于匹配基线。因此结论应是这种未来表征监督可以替代所测生成目标，而非“世界模型无用”或“所有任务都不需要想象”。[表1、19–21]

训练成本主张也有明确条件：缓存冻结未来目标后，Wan 每样本每更新的在线估算 FLOPs 降低 73.0%；这不包括一次性目标提取，也不是端到端训练时长降低 73%。对已经不在测试时生成未来的 FastWAM / ImageWAM，JAM 保留同一部署路径，主要节省的是训练阶段的视觉生成计算。[§4.5、附录B]

把三个问题分开

维度可能选择JAM 如何处理
骨干初始化视频生成器、图像生成器、自监督视觉模型、VLM允许多种骨干；不把预训练来源绑定到下游损失。
未来监督不用未来、生成未来像素、预测未来冻结特征采用余弦距离约束当前特征的未来预测。
部署计算生成未来后控制，或直接生成动作仅保留当前上下文编码与动作预测；不执行 foresight 头。
future anchor把记录的未来图像编码成固定监督目标的网络可以是冻结骨干，也可以仅是 VAE tokenizer；不是在线环境或规划器。
随机 anchor随机初始化但随后固定的网络仍是与未来输入有关、稳定可重复的编码，不是每次独立采样的噪声标签。
foresight让当前表征含有预测示范未来所需的信息不是在部署时看见真实未来，也不等于动作条件动力学 rollout。

这里“没有视觉生成”专指策略微调和部署时不训练或执行像素生成任务。骨干本身可以来自生成预训练，动作专家也仍采用 flow matching。把 JAM 说成“完全非生成模型”会混淆视觉生成与动作采样这两件事。[§1、§3.2]

问题链：为什么重新设计未来损失

先前比较把不同变量绑在了一起

一个 VLA 与一个 WAM 的成功率不同，可能来自视觉初始化、训练目标、动作接口、参数规模、机器人预训练或部署计算。只比较两者结果，无法指出“生成未来”是收益的原因。FastWAM 与 ImageWAM 已经移除了测试时的视觉生成，却仍在训练时保留生成目标。JAM 再向前问一步：训练时是否也可以直接监督未来表征，而不要求复原未来像素？[§1–2]

为什么是预测未来，而不是对齐当前

对齐当前编码容易成为一项重建或蒸馏任务，未必要求策略表示物体会怎样变化。未来位置的目标则让当前特征承担一项额外责任：根据任务上下文预测示范轨迹将到达的状态。表1的未来 offset 明显优于当前 offset，支持“时间位置”确实重要。但对 Wan 要小心：anchor 对整段窗口使用双向注意力，offset [0] 也可能包含未来上下文，因此它不是严格的“完全没看未来”的教师对照。[§4.2、附录A.2]

为什么预测头可以丢掉

动作专家实际读取的是被辅助目标训练过的当前特征，而不是预测头输出的未来特征。foresight 梯度更新骨干后，预测能力可以作为表示的一部分保留下来；部署无需重新运行辅助任务。这和“先模拟几条候选轨迹，再选择动作”的世界模型规划有不同的数据路径。论文证明前者可行，没有在同一设定下否定后者的价值。

机制：未来只在训练标签一侧出现

切换目标构造、梯度路径和部署路径。结构依据图1–2、式3–4及附录A；为说明性数据流，不是实际 rollout。

优化的到底是什么

设当前骨干第 ℓ 层 token 为 h⁽ℓ⁾，冻结未来 anchor 在时间位置 k 的特征为 gₖ，训练头输出 ĝₖ = pₖ(h⁽ℓ⁾)。损失为 L = Lact + λF LF，其中 LF 对 token 与所选时间位置平均计算 1 − cos(ĝₖ, stopgrad(gₖ))。没有未来像素重建误差；梯度只进入预测头和当前策略骨干。目标 token 与当前 token 保持固定空间布局对齐，不使用物体追踪来寻找对应点。[§3.2、式3–4、附录A.2]

预测头不是一个单独线性投影：先把输入降维，经过两层共享的 pre-LayerNorm Transformer，再为每个时间位置配一个线性读出。Wan 默认是 3072 → 1536 的主干，两个时间读出，约 71M 训练专用参数；Ovis-U1 是 1536 → 768，约 16.5M。更多或更大的头并不稳定提高成功率；相同宽度下 Transformer 优于 MLP，说明 token 间信息混合有作用，但这仍只是指定配置的证据。[表8、13]

VAE-direct 不代表让低维目标经过一个新教师网络：作者把 Wan 的 2×2×48 latent patch 通过固定坐标重复和缩放升至 3072 维，保留范数与余弦相似度；Ovis 的 16 维 token 类似升至 1536 维。这种升维本身没有注入额外语义。Wan 默认 λF = 0.6，其余为 0.3，多个 offset 均分总权重，因此增加 offset 不会偷偷增加辅助损失总权重。[附录A.2–A.3]

训练与部署的控制变量

同骨干的生成目标与 foresight 对照保留数据、策略结构、优化器、训练预算和部署路径。LIBERO 上 Wan 训练 20k 更新、其余沿 ImageWAM 配方训练 21.7k，global batch 都是 128。比较不同骨干时，参数量、输入组织、动作接口与动作长度仍有差异；这组实验检验配方可适用性，不能单独识别哪类预训练天生更好。[§4.1、附录A]

表1支持的是“目标空间与架构相配”而不是越语义化越好。Wan 的 VAE 已保留一段变化轨迹；Yak 的 anchor 则把单个未来端点与当前图像、指令关联。作者提出这种时间输入差异可能解释最佳 anchor 的不同，但没有单独操纵时间输入来确证这一解释。[§4.2]

当前位置目标也不是同样有效：Wan 从 [0] 的 44.62% 提高到 [1,2] 的 55.58%；Ovis 从 [0] 的 69.65% 提高到 [1] 的 79.95%。把当前位置加回去分别降为 54.18% 与 72.58%。因此“不丢任何目标一定更好”不成立；总权重固定时，还涉及监督分配和特征冲突。[表1]

第二层：随机教师不等于不需要预训练

在固定 Wan anchor 类型下，把策略视觉骨干从预训练改为随机，LIBERO 从 97.45% 降到 71.15%（预训练教师），或从 97.65% 降到 84.40%（随机教师）。注意这些“随机骨干”实验仍保留预训练的动作专家、VAE 和文本条件器，不能称作从零训练。它说明的是策略骨干的预训练在该架构里很重要，而预测目标不必来自同一预训练语义空间。[表2、17]

第三层：配方跨骨干有效，但收益不是每个扰动都为正

采用共同 foresight 目标，LIBERO-Plus 上 Ovis-U1 为 79.95%、DINOv2-L 为 70.39%、Qwen3.5-2B 为 81.14%。更有解释力的是匹配动作-only 对照：Qwen 从 77.03% 到 81.14%，DINOv2-L 从 68.26% 到 70.39%。但 Qwen 的机器人初始状态扰动从 68.02% 降到 61.42%，DINO 的语言扰动从 86.48% 降到 80.74%。辅助预测改善平均值，不等于所有能力同步改善。[表3、14]

论文名称里的“2B”指 Qwen 骨干规模，部署策略连同独立动作专家实际约 3.60B。共享权重版本也可行：共享 2B / 4B 策略分别约 2.22B / 4.55B，Plus 为 79.61% / 80.68%。独立动作专家不是 foresight 必需条件，且单次结果不足以证明 81.14% 与 80.68% 有稳定差异。[表15]

评测覆盖、统计支持与饱和基准

机制探针支持什么，又不能证明什么

作者用冻结策略特征训练额外 MLP，分别复原当前与未来帧，并在互斥轨迹上评估。未来帧 PSNR：ImageWAM 19.43 dB，JAM [0] 19.29，JAM [1] 19.57；相比当前图像直接当未来的 16.13 有提升，但最佳方法相对 ImageWAM 仅 +0.14 dB。这支持未来信息更可读出，不能证明策略内部建立了完整物理模型。注意力可视化经过均值扣除、分位归一化和非线性显示处理，也只是 token 分配的描述，不是“因果上更会推理”的证据。[图4–5、9、附录D.5–D.6]

证据边界与研究启发

这项结论的强度来自控制变量，而不是标题。固定架构的对照说明，所测视觉生成目标不是获得良好控制的必要条件；加入未来位置监督又能超过只用动作目标。它把“利用未来数据”与“必须生成未来像素”切实分离了。

但所有控制测试都在仿真，论文未提供真实机器人验证。未来标签来自示范轨迹，且预测头不以候选动作作为显式条件、部署时被移除，因此它没有测试探索、反事实搜索、在线规划或因果干预。许多世界模型的用途不在这项任务定义里，不能由本文一并否定。

跨骨干结果也不等于预训练家族公平赛：视觉输入分辨率、token 数、动作接口、参数量和时间跨度都有变化。最佳 anchor、深度和损失权重仍需选择：Wan 的 λF = 0.4、0.5、0.7 都没有超过 FastWAM 的 LIBERO 平均值；把监督移到第20层降至 95.45%，EMA 教师也低于冻结教师。配方简单不意味着无需调参。[表10–12]

可迁移的研究原则是：把昂贵的未来分支当作可替换的监督工具，先问它是否改善实际读给动作的表示，再决定部署是否真的需要它。下一步更有信息量的实验，是在同骨干、同数据下比较几何终点、语义特征与运动轨迹目标，以及在真正需要分支预测的任务中比较“训练后直出动作”与“运行时规划”。这属于本页提出的后续检验方向。
