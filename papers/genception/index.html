GENERATIVE PRETRAINING · GENERALIST PERCEPTION · VIDEO DIFFUSION

GenCeption

视频生成模型不只会“画下一帧”，它的内部表征能否成为视觉版的通用预训练底座？这篇论文给出一个很强的肯定样例，也留下了一个尚未完全兑现的标题。

Letian Wang 等 12 位作者 Google DeepMind、多伦多大学等 ECCV 2026 · arXiv v1 · 19 页
研究目的

寻找一种更接近语言模型“生成式预训练 → 多任务后训练”的视觉路线：复用大规模文本到视频扩散模型已经学到的时空、几何和语言先验，把它改造成单次前向、由文本指令切换任务的感知模型，并检验这套骨干能否用少量、主要为合成的标注数据，在深度、法线、相机位姿、分割和关键点等异构任务上接近或超过专用模型。

核心结论

第一，论文真正证明的是“生成式视频预训练很适合迁移到感知”，而不是所有视频生成器天然就是通用视觉模型。GenCeption 需要监督式后训练、任务输出格式和文本任务提示，才能把 WAN 2.1 的潜在能力变成可评测的深度、法线、分割或关键点预测。

第二，最漂亮的工程动作是“少改主干”。作者把干净输入放在扩散终点 t=0，只走一次 DiT，并直接读取最后一层；稠密任务继续使用原 VAE 解码器。这让后训练尽量沿用生成预训练已经优化好的信息通路。

第三，“统一模型”是真实的，但并不完整。稠密任务共享骨干、VAE 解码器和 L2 损失；稀疏坐标任务仍要追加可学习 token 和 MLP，而且 3D 人体关键点在联合训练中严重退化，最终总表没有给出 generalist 结果。

第四，标题中最需要警惕的是“general-purpose”。模型能在一组已知任务间切换，不等于能靠自然语言零样本学会新视觉任务；论文也没有直接测试物理预测、反事实推理或行动，因此“通用世界模型”仍是解释，而非被实验封闭证明的事实。

WHAT “GENERAL-PURPOSE” MEANS HERE

先把“通用”拆开：统一接口，不等于开放能力

GENERALIST VISION MODEL（通才视觉模型）

英译中：用一套共享参数处理多种视觉任务，而不是每个任务各训练一套完整模型。

怎么理解：GenCeption 的“通用”首先是工程接口上的统一：同一个 DiT 接收视频与文本任务提示，同一个训练配方混合多任务数据。它还不是 LLM 式的开放指令能力——新增任务仍要设计目标表示、准备监督数据并再次后训练。

文本提示在这里是任务选择器

文本编码器把“输出深度”“输出法线”“分割某个表达式所指对象”等指令送入 DiT。前两类提示主要选择输出模态；表达式指代分割还真正利用了颜色、空间关系和运动语义。不能把两者混为同一种自然语言推理能力。

“Rothko Raymap”是数据格式工程，不是自动统一

相机位姿通常是矩阵或六通道射线图。作者把射线原点与方向分置在一张三通道图的中央和外围，使其能通过同一个 VAE。这个设计很聪明，但也揭示了范式的真实成本：任务特化从网络头与损失，转移到了目标数据格式。

WHY VIDEO GENERATION

旧世界的问题，不只是模型太小，而是预训练目标各缺一角

作者把理想的通用视觉预训练概括为三个要求：必须理解四维时空演化，必须和语言语义天然对齐，还必须已经被产业动力推到足够大的数据与算力规模。MAE / VideoMAE 擅长视觉重建但没有原生语言接口；CLIP / SigLIP 擅长语义对齐，却不以稠密时序生成作为目标；任务专用 foundation model 又常把能力固化在特定头和损失中。

视频生成任务给了模型一种“高压训练环境”

要连续合成 81 帧，模型必须维持对象身份、视角变化和运动连续性；要响应文本，它还必须把语言概念绑定到像素与动作。论文的直觉是：这些生成约束比遮住 patch 再恢复更接近真实世界的联合分布，因此产生的特征更适合几何与时序感知。

但“生成得像”不自动等于“理解得对”

生成模型可能依靠纹理相关性和数据记忆得到逼真视频，却没有可组合的几何或因果表示。GenCeption 的价值正是在于把这个哲学争论落成下游实验：如果同样的后训练数据下，生成骨干更容易收敛、精度更高，那么至少说明它包含更可用的感知先验。

GENERATOR → PERCEIVER

真正的关键：把“逐步去噪”改成“终点读出”

公式拆解 · 为什么对 DiT 输出取负
v = ε − x0   ⇒   −v = x0 − ε

这条式子回答：原 WAN 的 Rectified Flow DiT 习惯预测“从干净样本指向噪声”的速度，后训练时怎样把它的输出方向转成更接近干净视觉目标的初始化。

x0
扩散预训练中的无噪声视频 latent；在 GenCeption 后训练中，输入端也直接使用干净视频 latent。
ε
高斯噪声端点。标准生成过程会沿多个时间步逐渐从噪声走回视频。
t = 0
Rectified Flow 的无噪声终点。模型只在这里执行一次，不再进行迭代采样。
−v
作者送入损失或解码器的实际输出；他们报告它比原始 v 更接近目标 latent，因而收敛更快、效果更好。
直觉读法：这不是证明“负速度严格等于任意感知目标”，而是一种与预训练几何相容的读出方向。真正让它成为深度或法线的，是后续监督式多任务训练。

稠密任务：把一切视觉化，再用同一个 L2

深度和二值 mask 复制到三个通道；法线和 DensePose 本来就是三维量；六通道相机 raymap 则被空间拼成三通道图。模型在 VAE latent 空间用统一 L2 训练，任务间权衡只通过数据混合比例处理。

公式拆解 · 深度怎样适配统一 RGB 空间
d′ = clip(α log(d + 1), 0, 1)

这条式子回答：如何不用尺度不变深度损失，也把不同场景的深度放进 VAE 熟悉的 [0,1] 三通道范围。

d
先除以该视频场景中位深度后的相对深度；这一步消除单目深度的全局尺度歧义。
log(d+1)
压缩远距离数值范围，让近处结构在有限像素动态范围中保留更多分辨率。
α
控制近场与远场关注比例的缩放系数；论文称其可动态调整，但正文未给出系统性敏感度实验。
clip
截断到 [0,1]，使目标能作为标准 RGB 风格视频由共享 VAE 处理。
直觉读法：统一损失并没有消灭任务知识，而是把它迁移到标签预处理。模型工程更统一了，数据工程仍然必须理解每个任务的歧义和数值范围。

合成数据：7500 段核心人类视频，再拼接任务数据

核心合成集用 800 个 RenderPeople 人体资产和 200 个 CMU 动作，在多种三维场景、HDRI 背景、焦距和相机轨迹中生成 7500 段视频，同时渲染法线、深度、mask、2D/3D 关节和相机位姿。训练还加入 TartanAir、Virtual KITTI、MVS Synth 的深度/相机标注；表达式指代分割使用 MeViS、Ref-COCO、YouTube-VOS 等真实数据。因此准确说法是“绝大多数任务主要依赖合成后训练数据”，不是所有任务都纯合成。

训练与推理成本并不小

模型以 WAN 2.1 的 1.3B 和 14B 版本为底座，输入 81 帧、480×832、24 FPS；训练使用 256 张 v6e TPU，batch size 64，训练 15000 步。14B 模型单个 81 帧 clip 在一张 v6e TPU 上需 10.03 秒、42.8 GB 显存，对应约 8 FPS；它比 50 步扩散快很多，但仍不是轻量实时感知器。

“7×–500× 更省数据”应该怎样读

它指的是感知后训练标注量，不是端到端学习总数据。WAN 2.1 在进入 GenCeption 之前已经接受过大规模视频生成预训练，而论文没有给出那部分数据和算力的等价折算。正确结论是“生成底座显著降低了新感知任务的标注与后训练成本”，不是“它总共只看了 1.23M 帧”。

第四层：所谓“涌现”更像预训练知识被重新读出

后训练核心数据只有单个人体合成视频，但模型能在真实视频中处理多实例、猫、蜥蜴、犀牛和机器人。这个现象很有启发性，却主要是定性图示。更重要的是，WAN 的生成预训练本来就可能看过广泛真实类别；因此它证明的是“人类合成后训练没有完全抹掉底座的跨类别先验”，不能证明模型只靠 7500 段人体视频自行涌现出动物知识。

TECHNICAL DEBT & BOUNDARIES

它是通用预训练的强证据，还不是视觉版 GPT 时刻

证据较强

生成骨干含有高价值感知先验

相同后训练视频下，WAN 2.1 在跨数据集深度评测中明显优于 V-JEPA 与 VideoMAE；从零初始化 DiT 几乎不收敛，迁移更多预训练层则训练损失持续降低。

只能有限外推

一个模型能做多任务

统一 generalist 在多项任务保持竞争力，分割还受益；但深度、相机和指代分割出现回退，3D 人体结果缺失，说明任务冲突尚未解决。

仍待验证

通用视觉智能与世界模型

论文没有测试零样本新任务、交互式物理预测、反事实、长期规划或行动闭环；这些能力不能从一组监督感知 benchmark 自动推出。

不是“只靠 prompt 就学会新任务”

文本 prompt 在训练过的任务集合中选择模态。新增一个任务仍需决定如何把标签塞进 RGB 或 token 空间、收集监督数据并重新后训练。这和 LLM 仅凭上下文示例完成新任务仍有本质距离。

“统一损失”把复杂度搬到了表示和数据混合

深度要先做中位数归一化与对数映射，相机位姿要发明 Rothko raymap，坐标任务还需额外 token；任务冲突则靠数据 mixture ratio 管理。架构更简洁，但任务工程并没有消失，只是换了位置。

预训练目标的因果归因仍不够干净

WAN-S 与 VideoMAE-G 虽参数量接近，但原始预训练数据、计算量、网络细节和文本条件并未严格匹配；WAN-L 更达到 14B。当前结果无法区分收益分别来自生成目标、模型规模、训练数据多样性还是语言条件。更强的结论需要同架构、同数据、同算力的预训练目标对照。

专用 SOTA 对比不是完全同口径

不同模型的参数规模、预训练数据、训练任务和评测协议并不一致。GenCeption 在若干指标上第一或第二，另一些指标落后；更稳妥的说法是“一个共享模型在很宽的任务谱上保持了罕见的竞争力”，而不是“所有任务全面击败专用模型”。

复现与效率仍有门槛

项目页当前把代码标为 TBA。训练依赖 256 张 v6e TPU，14B 推理占 42.8 GB 显存；共享文本编码器本身约 10 GB。论文证明了扩散到单步的巨大加速，却没有展示消费级硬件部署、流式延迟或长视频扩展。

“合成到真实”并不等于没有真实世界知识

感知后训练大多使用合成标签，但底层 WAN 的生成预训练来自大规模真实/网络视频分布；表达式指代分割还明确混入真实数据。因此 sim-to-real 应理解为“合成监督激活并校准了已有真实世界先验”，而不是从封闭模拟器中凭空学会真实世界。
