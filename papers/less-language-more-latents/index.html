Less Language, More Latents

LADA：把语言对齐集中到小型意图空间，让其余驾驶数据继续发挥作用

Alexey Zakharov、Kemal Oksuz、Puneet K. DokaniaBosch / Five AI预印本 v1 · 20 页
研究目的

在图像和专家轨迹充足、语言指令标注稀缺时，训练仍能接受语言导航的驾驶 VLA。

核心判断

LADA 用约 5% 的高层指令与反事实标注，在 Bench2Drive 闭环驾驶中超过完整语言监督的 SimLingo。贡献在于把“理解指令”和“执行动作”通过小型离散意图空间拆开；节省的是语言标注，仍依赖全量专家轨迹、反事实数据生成和额外训练阶段。（表 1、§6）

潜动作是中间接口，不是控制量

VLA 是从图像和语言指令预测动作的模型。本文的潜动作是 25 个可学习代码之一，用来表示场景中的粗粒度路径意图；它既不是方向盘角度，也不是一条固定轨迹。同一代码在不同道路上可以解码成不同路径，代码与“左转、沿路行驶”等语言命令也不是一一对应。（§4.1、图 4、附录 A.2）

稀缺的是语言，轨迹里已有行为信息

只拿有语言的少量帧训练，会浪费大部分驾驶示范；先训练指令分类器、再给其余帧补标签，又容易传播分类错误。作者改为先从全量“图像＋路径”学习可执行意图，再让少量语言对齐这个空间。“未标注”在此仅指没有语言，绝不是没有动作监督。（§3–4）

三阶段：学意图、翻译指令、执行意图

第一步：限制代码能携带的信息。潜动作模型读取前视图像和约 20 米、20 点的路径，通过量化瓶颈重建路径。主配置只保留一个 25 类代码，解码器还读取图像，因而代码不必存下完整几何细节。训练同时用少量高层命令（HLC）辅助分类来促进语义对齐，所以主实验的代码空间并非完全无语言监督。容量过大容易编码过细的轨迹，太小又会混淆意图。（§4.1、附录 B）

第二步：让翻译器必须听指令。翻译器是图像与指令到代码的分类器，有语言的帧过采样到每批约 30%，其余帧以空指令训练。只有一个场景对应一个命令时，模型可能直接看图猜代码、忽略语言；作者用 action dreaming 为同一场景生成其他可行指令及其路径，再通过冻结的潜动作模型得到替代代码。改变的是“指令＋目标”，不是仅换一种说法。（§4.2、附录 C）

第三步：在全量示范上学执行。沿用 SimLingo / InternVL2-1B 的驾驶主干，输入图像、当前速度和代码，分别预测几何路径及时间速度路点，再交给 PID 控制。训练不再需要给每帧配语言；部署仍需串联翻译器和驾驶模型两次推理。（§4.3）

闭环有效，但不是每项能力都更强

220 条 CARLA 路线；DS 与成功率均越高越好（表 1–2）
方法 / 条件DS成功率 %

DS 综合路线完成度与违规惩罚；成功率要求在时限内完成且没有交通违规。LADA 相对完整语言基线高 1.90 DS、4.68 个成功率百分点。表 1 的 LADA 给出 3 个种子标准差，但基线没有同等误差条，不能由均值差直接断言统计显著；让行、交通标志与紧急制动能力也未全面超过完整语言基线。

机制证据更有解释力：去掉反事实监督，成功率下降 5.46 个百分点；几何 k-means Anchor 仅有 79.97 DS / 54.01% 成功率，提示不是随便聚类轨迹就能替代学习的意图空间。不过 IDM 不含 CF，不能把它与 LADA 的全部差距归因于潜动作预训练。（表 1–2）

约 1% 标签时为 84.65 DS / 61.81%，约 20% 时为 88.01 / 70.53%，说明该实验配置在 5% 附近已趋饱和。作者指出预算消融共用驾驶模型，因而不能理解为三阶段全部按不同预算重训。更大的 64 / 256 类代码反而降低翻译准确率；场景交换重建支持代码依赖视觉，但还不是每个代码都具有稳定语义的严格证明。（§5.3–5.5）

节省标注成立，现实可迁移性仍待验证

仿真提供了关键捷径。全部实验来自约 140 小时、200 万帧的 CARLA 专家示范，反事实轨迹生成依赖仿真特权状态。真实日志里“如果司机被要求变道会怎样”并不现成，因此 CF 如何获得可能比语言标注本身更难。（§3、§6）

能力与成本发生了交换。取消 VQA 和思维链（CoT）后，模型不再具备相应解释或问答能力；代码主要表达路径，翻译器反事实训练还排除了纯速度指令。现有证据不支持任意自然语言驾驶要求。三阶段训练与两个部署模块也没有给出完整成本、时延对照，不能把语言标签比例直接当成端到端成本比例。（§6、附录 C）

我的判断：最有价值的是用“可执行、可分类”的中间意图接口重新分配监督，而非笼统宣称语言不重要。下一步应在真实数据上核验反事实来源、语言指令服从与部署时延，尤其比较同样 CF 预算下的直接语言模型。
