ECHO

先辨认是否需要纠正，再让状态信号参与动作去噪

Yufeng Liu 等 · 21 页2026-10-22 · 用户提供的 PDF 版本

总体判断：ECHO 的贡献不是仅给 VLA 添加两个分类输出，而是用同一模型共同生成动作、停止信号和失败信号，并通过注意力结构与不同去噪速度让状态估计反过来影响动作。五项真实机器人任务、相同成功/恢复动作示范下的对照，以及阻断信号到动作通路的消融，都支持这个机制有实际价值。最重要的边界是：“不需要逐帧进度标注”不等于无需人工监督；它仍需要子任务边界、成功/失败类别、人工接管与恢复轨迹。信号被干预后动作会变，也不自动证明每次变化都更安全。〔§3–4，表1–5〕

例如插花时，停止信号低而失败信号高，表示任务还应继续，但当前状态需要纠正；两者都高才表示终止失败。把失败和终止拆开，能够避免“发生错误就停止”的单一分类逻辑，并为恢复动作提供可学习的条件。

两个信号表达四种组合，动作专家如何读取它们？

停止 SS失败 FS执行含义
低低正常进行
低高进行中出现可恢复失败，动作应可能纠正
高低成功完成，停止
高高终止失败，停止或交给外部处理

输入是当前视觉、机器人状态与子任务语言指令；输出包括 H×da 动作块，以及各 H×1 的 SS、FS。最终每个信号在动作块内求均值，阈值默认均为 0.5。公式上的三类状态先由 SS 判断 ongoing，再在停止时用 FS 区分成功与失败；ongoing 内的高 FS 进一步表达可恢复错误。〔式4–7〕

两列信号不是关节命令，不会作为两维额外电机动作执行；它们是模型内部生成并读取的状态表示。作者把动作、SS、FS 分别投影为 token 组，使用分开的 MLP 和输出投影，在共享 Transformer 中交互。H=60 时生成 token 从60增到180，因此“只加两维”不能理解成注意力开销完全不变。〔§3.2.3，附录A.4〕

数据边界本身可以监督停止，但失败起点并不总已知

成功示范末尾天然提供停止边界，失败 rollout 末尾提供终止失败边界，人工接管前片段末尾则是已确认的可恢复失败。三种边界语义不同：前两种意味着停止，接管意味着仍应继续修复。ECHO 利用这些区别构造信号，而非要求人对每帧标一个精确进度分数。〔§3.1–3.2.2〕

动作块可能越过当前子任务的最后有效时刻 T。padding mask pᵢ 在有效位置为0，越界后为1；动作目标重复最后一个有效动作。对成功片段，SS 的目标就是这个 mask；它会随块跨过终点的比例增大而逐渐抬高其均值。因此这里的状态信号与动作预测 horizon 以及分段边界直接相关，不是任意时刻独立标注的真实物理状态。

失败片段知道终点失败，却不知道真正何时开始失败。作者对没有 padding 的块不监督 FS；含 padding 的块用前0后1的目标。这个弱监督选择避免给整个失败轨迹贴1，但边界前仍用0，可能把已失败但尚未结束的时刻看作未失败。恢复数据提供了另一条从失败到正常的连续监督，用以补充该缺口。

四类数据、注意力隔离与异步去噪共同起作用

恢复片段可能仅修正局部错误，结束不一定等于整个任务完成，所以不学习其 padded 动作，也不把其边界误标为停止。恢复 FS 用 u=(t−t₀)/(t₁−t₀)、nₜ=round(Hu) 构造前 nₜ 个0、后 H−nₜ 个1的向量；其均值约为1−u。它是一种由片段位置推导的训练目标，不能把它当成精确标注的物理失败概率。〔表1，式8–9〕

动作读信号，信号读动作，但 SS 与 FS 不直接互读

动作 token 能关注多模态 prefix 与两类信号；SS、FS 也各自读取动作 token，形成双向信息交换。两信号之间的直接注意力被阻断，分别保留“该不该停”和“有没有失败”的语义，避免因经常共同出现而相互复制。这并不意味着两信号统计独立，也不阻断通过动作 token 的间接联系。〔图2，§3.2.3〕

信号在动作尚未完成时先变干净

流匹配使用 xτ=(1−τ)x₀+τε，τ从1噪声走向0干净。信号时间 τq=max(0,(τA−τclean)/(1−τclean))，实际 τclean=0.5。因此当动作仍处于 τA=0.5，信号已经到0并固定，剩余动作步骤可以读干净状态。训练也使用同样的分组噪声时间、对应监督 mask 和损失权重；它不是仅在推理时强行提前截断一个同步训练模型。〔式12–13〕

OOD 收益大，ID 不是处处提升

插花 ID 评分从9.33降为8.67，OOD 从2.00升为8.00；抽屉 ID 从8.40到8.93，OOD 从2.40到6.87。每条件15次；OOD 主要是物体位置变化，不能称为跨任务或跨机器人泛化。作者认为状态信号帮助调用已学恢复行为，这一解释与结果一致，但还应结合干预和消融，而非从平均分直接推出。〔表4〕

切断信号到动作的通路，改善就明显变小

插花消融中，完整 ECHO 评分8.33；去掉动作对状态信号的注意力后降到5.00，而帧F1仍90.78、轨迹F1为100。这很好地区分了“监测准”与“监测帮助控制”。全注意力版本7.67，同步去噪7.33，共享MLP6.67；它们支持分离信号与异步条件化，但单任务30次及标准误也限制了精细排名解释。〔表5〕

固定 SS=0、将 FS 在每个噪声水平强制设为0或1时，FS=1诱导重复向上的恢复动作，FS=0更偏向目标动作。该干预证明信号对输出有因果作用，却不证明强制FS=1普遍改善成功率。终止失败数据从50增到250条，帧F1从81.94升到92.18；完成评分8.00、8.67、8.33、8.33没有单调增长，也说明识别数据与纠正动作数据承担不同职责。〔图5–6〕

开销小于大模型外部监控，仍有可量化成本

RTX4090 上推理从115 ms变120 ms，增加5 ms；主实验查询5 Hz。补充 LIBERO-Recovery 用150个固定场景、每模型4,500次试验，成功率从32.67%升到34.76%，状态准确率89.97%。该版本只用三类数据，且仿真收益远小于部分真机评分改善，不能把所有设置合并成一个统一增幅。〔§4.5，附录A.4、A.10〕

弱监督、额外数据与错误反馈是主要外推边界

第一，“无需细粒度进度标签”有明确范围：多子任务 episode 仍手工标边界、指令，操作员识别可恢复失败并示范修正。训练采样比例成功:终止失败:接管前:恢复为20:1:2:20；恢复数据占相当比重，无法把效果描述成只增加两维输出即可免费获得。

第二，状态预测与动作互相影响也可能互相放大错误。SS 提前偏高可能造成过早停止，FS 错判可能调用不合适的恢复动作。本文已有真实任务与组件实验，尚未系统量化异常信号对闭环行为的最坏后果。更具体的验证是按误报/漏报类型注入受控偏差，测最终成功率、恢复循环和额外接触，而非只看F1。

第三，优势主要在固定机器人、五任务及其位置变化上建立。低延迟和信号可读性使其很适合用于单模型的任务执行反馈，但不等于通用安全检测器。最值得迁移的原则是：失败数据负责告诉模型哪里不对，恢复数据负责告诉模型接下来怎么做；将两者在监督和动作通路中明确分工，比增加一个没有控制接口的状态头更有解释力。
