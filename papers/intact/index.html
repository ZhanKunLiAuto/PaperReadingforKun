INTENT TO ACTION · JEPA · DIRECT CONTROL · OPTIONAL SEARCH

INTACT

一篇把“世界模型知道动作会造成什么”推进到“世界模型知道想要这种变化该做什么”的论文；它不删除前向模型，而是补上一个训练和部署共用的意图—动作接口。

Junhan Sun、Hao Zhao、Guofeng Zhang 浙江大学、清华大学 AIR、InSpatio、RoboParty Lab arXiv v1 · 28 页
研究目的

利用离线专家轨迹中已有的“状态变化—动作”配对，把前向潜世界模型需要在部署时用 CEM 反演动作的高成本逆问题，摊销成一个可直接调用的条件动作分布；同时让动作监督反向塑造视觉表示，使搜索从必需步骤降为可选局部验证。

核心结论

第一，INTACT 不是把 inverse dynamics head 随手加到 LeWM。局部 inverse branch 与 goal-conditioned imitation branch 本身都不新；完整方法的不可约部分，是它们使用相同输入语法、共享同一动作预测器，同时对 endpoint 采用不对称梯度。

第二，“同构”不是说两个潜变量数值相等。它指两类调用的图结构相同，并通过同一个条件动作律建立语义对应；论文明确没有最小化 ||mgoal−mlocal||²。

第三，搜索不是被证明无用，而是被重新定位。Direct 已提供高质量计划；以它为中心的 128×3 局部 CEM 还能略升成功率，而从零均值单位方差开始的宽搜索会浪费已经学到的接口。

READING OBJECT

读懂 INTACT，必须分清“状态”“意图坐标”和“动作律”

FORWARD–ACTION GAP（前向—动作缺口）

英译中：训练学的是“动作如何改变状态”，部署问的却是“想改变成这样该做什么”。

怎么理解：LeWM 的 Fφ(z,a) 可以 rollout 候选动作并打终点距离，但没有从目标变化直接读动作的映射，于是 CEM 必须在原始动作空间反复采样、预测、筛选和重拟合。

CONDITIONAL ACTION QUOTIENT（条件动作商类）

英译中：在固定当前状态 z 时，把会诱导相同专家动作分布的不同 endpoint condition 视为同一类。

怎么理解：门口前的两个不同远期目标，当前第一步可能相同；真实下一状态与某个远期目标也可能离得很远，却要求相同动作。等价关系由动作律定义，不由潜空间欧氏距离定义。

ISOMORPHIC（同构）

英译中：结构上，local 与 goal 调用都有 [状态、意图、状态×意图、上一动作] 四个槽并共享参数；语义上，两类意图通过同一动作分布映射建立对应。

避免误解：它不宣称整个潜空间存在全局线性同构，也不宣称跨任务可用一个统一 actor；实际多任务设置共享 encoder，但 Forward 与动作 heads 仍按任务区分。

WHY SEARCH BECOMES MANDATORY

如果训练时只学正向动力学，部署时就只能数值反演

MECHANISM

同一条轨迹同时提供“真实变化—动作”和“未来目标—动作”两类监督

公式拆解 · 两类 intent 为什么必须同时存在
mlocal = zt+1 − zt   ·   mgoal = sg(zg) − zt

这组公式回答：训练怎样同时获得物理可信的局部变化与部署前可计算的目标变化。

zt+1−zt
真实执行一个 action chunk 后观察到的局部变化；endpoint attached，动作损失能塑造两端 encoder 表示。
sg(zg)−zt
当前状态到同一轨迹未来目标的潜位移；未来目标 stop-gradient，但当前 zt 与 actor 仍更新。
sg
stop-gradient，只作用于 goal branch 中作为部署锚的那次 zg；同一未来 latent 作为物理后继时仍可塑。
局部 intent 解决“表示里有没有保留可控变化”，目标 intent 解决“动作前能否直接查询”；前者单独会在部署时循环依赖未来，后者单独更像目标条件行为克隆。
公式拆解 · 完整耦合目标
LST = Lworld + λinvLlocal + λgoalLgoal

这条公式回答：前向世界预测与两种动作似然怎样在一次端到端训练里分工。

Lworld
LeWM 的前向潜预测 + SIGReg，保留接触、障碍和未来视觉等比当前动作更丰富的信息。
Llocal
同一个 Gη 在 local intent 下对示范 action block 的负对数似然。
Lgoal
同一个 Gη 在 goal intent 下对同一示范 action block 的负对数似然。
完整方法不是要求两种 intent 长得一样，而是要求它们在各自有数据支持的条件下，被同一个 proper likelihood 解释成正确动作分布。

TECHNICAL DEBT & BOUNDARIES

它消除了一个接口错位，没有消除离线控制的所有分布外问题

证据较强

直接接口能替代宽搜索

单任务三训练种子、共享四任务完整 factorial、actor-disabled 对照和规划预算审计都支持 Direct-first。

只能有限外推

动作商类只在示范支持上识别

单条专家轨迹不能告诉模型所有同样有效的动作，也不能保证任意反事实目标都有正确条件分布。

仍待验证

真实机器人与跨形态统一 actor

现有四任务都是仿真、固定图像目标、离线专家轨迹，并使用任务特定动作 heads。

Direct 的对角高斯均值会抹平多模态

路口或接触切换可能存在多个都正确的动作 mode，而均值可能落在两个 mode 之间。论文提出 mixture actor、按不确定性触发验证与从 learned conditional 采样作为后续方向；当前 Direct 强结果不能证明均值策略在所有多模态任务都安全。

目标位移不是障碍感知路径

mgoal=zg−zt 保留方向与距离，却只是一阶请求；绕障、接触切换与多段拓扑不一定能由一条潜位移表达。非线性 Gη 可以按状态解释，但正确性仍依赖示范覆盖。

递归 rollout 仍会进入预测状态分布

第一步用真实编码状态，之后的计划内部状态来自 Fφ 预测；误差会累积。训练与部署共用 goal intent 构造消除了动作 proposal 接口错位，却没有消除自回归状态漂移。

三训练种子仍是粗粒度不确定性估计

作者已完整跑三训练种子、三评测种子与 E1–E5，明显优于只报单点；但其限制章节仍主动承认三种子不足以精确估计训练方差。若比较 1–2 个百分点的小差异，仍需更多种子或置信区间。

官方评测与 CLEAR 审计不能混用

官方 LeWM protocol 保持可比性，但 CLEAR-LeWM Moderate 修复 Reacher 与 TwoRoom 的评测问题并移除初始已成功样本。Reacher 从官方 97.67% 降到 Moderate 49.56%，说明 headline SR 强依赖协议；论文将两套数字分开是必要的。

“约 300×”只指规划器侧时延

Direct 的 2.9–5.5 ms 与 CEM 1.48 s 是 planner-side audit，不包含视觉编码、环境 I/O 或更大 VLA backbone。它有力证明数值搜索瓶颈被移除，但不等于整个机器人系统端到端快 300 倍。
