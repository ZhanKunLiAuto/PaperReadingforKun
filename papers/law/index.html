SEMANTIC PROGRESS · HYBRID EXPERTS · CLOSED-LOOP CONTROL

LAW

用语义子任务进度，把“想做什么”“动作怎么做”和“是否做完”接起来。

Jiajun Cao、Kai Tang 等 20 位作者北京大学 · 北京人形机器人创新中心arXiv v1 · 27 页

总体判断：LAW 是一项有实证支撑的机器人闭环系统工作，最有价值的贡献是把语义子任务同时用作规划目标、动作条件、完成判断、记忆边界和价值学习的信用分配单位。它在已有 WAM 上得到稳定的平均收益，三个真机长任务的提升尤其明显；MoTE 的对照也支持共享专家及其放置位置确有作用。不过，这些证据主要来自经过任务专门训练、人工定义语义阶段的场景，尚不能推出通用开放任务规划、可靠失败恢复或跨机器人迁移。[§3、表5–11]

阅读时应先抓住两点。第一，题目里的“统一”发生在多个模块围绕同一进度接口协同，训练也分阶段进行。第二，默认 Fast-WAM 路线在推理时不采样显式未来图像：视频预测提供训练信号，在线由 VLM 对动作候选直接估值。把它理解成“在脑中生成多条未来视频，再选最好的那一条”，会误读本文最核心的计算路径。[§3.1、§4.1]

研究目的

让机器人持续回答：当前子任务是什么？执行到了哪一步？这段候选动作是否有助于完成当前目标？何时应该切换目标？

用“整理抽屉”理解整个系统

论文的真机 Organize 任务要求把三个彩色方块放入对应抽屉并关好。作者将其定义为九个语义阶段：对每个方块依次“开对应抽屉 → 放入方块 → 关抽屉”。其中“放入方块”可以包含接近、抓取、搬运和释放等多个低层动作；语义子任务由一个可识别的目标组织，而非固定时长或每个关节动作各算一步。[附录B、E，表15]

输入：全局语言指令、一个场景相机和两个腕部相机的 RGB 图像、机器人状态，以及各自编码的历史。输出：两个机械臂的绝对末端位姿与夹爪目标。默认动作是 16 维：每臂三维位置、四元数旋转和一个夹爪量。WAM 使用 16 维末端状态；VLM 的 state 专家另接收文本化的 14 维关节与夹爪状态。二者并非简单地消费完全相同的输入张量。[附录D]

  1. Planner 定当前目标。根据指令、图像和记忆，预测尚未完成的子任务序列；取第一项，例如“打开第一个抽屉”。
  2. WAM 提议如何动。在该子任务和当前状态条件下，以不同噪声生成 32 个候选动作块；每块长 32 步。
  3. Value 判断哪个候选更有用。给候选打局部价值分，取 top-8，按权重融合成一个动作块，执行其前缀。
  4. State 在执行期间检查完成情况。若尚未完成，下一轮继续同一目标；接受完成信号后，保存边界观测，重新规划剩余任务。

于是“抽屉已经打开”不仅是一个自然语言描述。它会改变下一次动作生成的条件、价值评估的目标、被高保真保留的历史帧以及 planner 的调用时机。这种同一个事件驱动多个模块变化，才是论文所说的语义进度接口。[式1–6、Algorithm 1]

长任务的瓶颈，是目标、反馈和历史脱节

一份初始计划无法证明某一步真的完成。如果“开抽屉”失败，继续执行原定“放方块”就可能把物体放在柜子外。反过来，如果其实已经完成却迟迟不切换，也会重复操作。只把一个语言规划器接到策略前面，还缺少执行结果如何更新目标的规则。

物理可执行不等于符合当前目标。同一观测下可能有多条平滑、合理的动作轨迹，但只有其中一部分能推动当前阶段。例如向抽屉靠近和向另一个物体靠近都可能像训练动作；需要一个以当前子任务为条件的评估器区分它们。

当前图像可能缺少“之前做过什么”。被关上的抽屉外观不能直接说明里面是否已放入方块。保留全部图像会增加计算；把历史都池化又可能丢失边界处的物体位置和接触状态。LAW 用“近期、子任务边界、较早历史”三种保留精度来做取舍。

这些问题以前分别出现在语言规划、价值引导控制与记忆策略中。本文增量主要在于把它们放在统一的执行进度框架下，同时改进 WAM 的视频—动作联合计算。作者在相关工作中承认这些已有技术基础；本页不据此声称某一个组成部件是首次出现。[§1–2]

一个慢语义循环，连接一个快动作循环

规划、评分和完成判断，调用频率不同

Planner 在 episode 初始化和接受子任务完成时调用。WAM 候选生成与 value 评分发生在每次动作块决策时，二者存在同步依赖。State 在动作执行期间异步运行，正文报告单次约 60 ms，流水并行使吞吐提高 15%。因此，“异步”具体指完成判断与执行重叠，不能把整套系统都理解成无等待控制。[§3.2、图4]

防止异步反馈串台，是实现中的重要细节。每次剩余计划的索引都从 1 开始，所以仅凭“第几个子任务”不能唯一识别一次执行。作者额外维护单调递增的实例编号 u，并给预测附上观测采集时间。只消费属于当前 u、比上次已消费结果更新的预测，且丢弃被更新结果取代的旧结果。切换时存的是控制循环转换当下的观测，而非之前用于完成判断的旧图像。这使“什么时候看见完成”和“什么时候真正切换”被明确区分。[§3.1、Algorithm 1]

还需要注意：state 训练时有一个辅助 failure 预测头，但部署算法的语义事件只有 CONTINUE 和 ADVANCE。辅助失败监督帮助区分“失败”和“做完”；论文没有在 Algorithm 1 中实现基于 failure 头的回退、撤销或重新抓取分支。持续重采样动作可能纠正局部偏差，但这与专门的失败恢复机制是不同强度的主张。

VLM 的专家按职能切换，WAM 的专家按 token 路由

第一类专家在 VLM 内。Qwen3-VL-2B-Instruct 的语言与视觉骨干冻结，planner、state、value 各有 LoRA 适配器与对应输出。LoRA 可理解为在冻结的大权重旁训练低秩增量；此处按控制职能选择适配器，并非每个 token 动态选择专家。Planner 和 state 的 rank 为 64，value 为 128，三者合计增加约 100M 参数。这样既复用视觉语言基础，又减少三种训练目标相互干扰。[§3.2、§4.1]

Planner 通过自回归监督学习剩余子任务序列；state 用完成二分类与辅助失败二分类共同训练。Value 将候选动作编码为 token，与图像、指令、当前子任务和历史共同输入，使用一个 query token 聚合信息，输出 101 个 value bin 的概率，最终 Q 值是各 bin 中心的概率加权平均。它是动作条件化的 critic，不是让语言模型自由生成一段“这个动作很好”的文字。

第二类专家在 WAM 内，这就是 MoTE。视频分支和动作分支先把 Q/K/V 放到共同注意力空间交流信息，随后各自继续变换。LAW 在这种 mixed attention 之后加一层带残差的专家计算，让已经交换过跨模态信息的表征，既可走模态专属变换，也可走两种模态共用的变换。[§3.3、图5]

两路记忆共享时间点，使用不同表征

VLM 的图像 token 与 WAM 的 VAE latent 并不兼容，作者因此分别编码同一组历史观测。VLM 记忆服务规划、完成判断和价值估计；WAM 记忆服务视频预测训练与动作生成。“双流”指这两个原生特征空间，而不是把一个模型的隐状态直接传给另一个模型。[§3.4、式13、图6]

远期：保留粗略上下文

当前子任务较早历史每 4 步采样，已完成子任务每 16 步采样；空间平均池化为每个旧观测一个摘要 token。

这个设计的理由很具体：近期帧有助于判断运动和刚发生的接触；“方块刚放入抽屉”的边界帧有助于记住当前画面看不见的状态；更久以前的细节可压缩。采样沿 t mod 4 对齐。这里的步数是论文采样索引，不宜不经说明直接换算为相机视频秒数。压缩的是空间分辨率，也不等于历史 token 总数恒定；任务越长，摘要和边界仍可能增加。

失败的整条轨迹，不应抹去成功的前半段

假设“开抽屉、放方块”都成功，最后关抽屉失败。如果只在整条任务最终成功时给奖励，前面正确的动作也拿不到正信用。LAW 为每个成功子任务的终止动作赋奖励 1，其余为 0；最后失败的子任务无正奖励，未观察到的后续子任务不进入监督。价值因此表示当前语义目标下的折扣回报，不是整条任务最终成功的保证。[§3.5]

评分之后执行的是融合动作

部署取 32 个候选中的 top-8，权重 wn ∝ exp(Qn/T)，默认 T = 1；一个候选的权重在整个时间块内共享。位置与夹爪目标按权重线性平均。旋转用 Markley 四元数均值：构造 M = ∑ wnqnqn⊤，取最大特征值对应的单位特征向量。因为 q 和 −q 表示同一个旋转，直接平均会互相抵消，而这种外积形式对符号翻转不敏感。[式16–17]

32 步动作以 0.06 秒为步间隔，覆盖约 1.92 秒；这只是候选时域。机器人执行前缀后重采样，论文正文没有在此给出统一前缀长度，因此不能用 1.92 秒推断实际观测闭环频率。三步去噪也只描述 WAM 的采样步数，不包括 value 批量评估、规划和通信耗时。

分阶段训练，把生成器与评估器分开优化

第一阶段依次训练 planner、state，WAM 则独立进行视频—动作联合训练；第二阶段冻结这些组件，仅训练 value 的适配器、动作编码器、query 和分类头。WAM 以 Wan2.2-TI2V-5B 与预训练 ActionDiT 初始化，训练视频/动作 DiT 与 MoTE，其余预训练模块冻结。表1分别列出 planner 3,000 步、state 50,000 步、WAM 30,000 步、value 50,000 步；WAM 用 32 张 GPU，其他阶段各 16 张。论文未给出完整 GPU 小时，不能据“2B VLM”推断整套训练很轻。[§4.1、表1]

作者另外报告按子任务完成比例计算的 Score：LAW 平均 84.06，π0.5 为 55.50，Fast-WAM 为 51.87。这说明未完成整条任务时，也往往推进得更远。但 Score 是部分进度，不能把 84.06 写成 84.06% 的完整成功率。每组仅 20 次也意味着一例成败会改变 5 个百分点，单任务小差距不宜过度解读；这里的大幅平均差距具有方向性价值，却仍缺少真机逐模块消融。

RoboDojo：相对更好，绝对成功率仍很低

表3在 Generalization、Precision、Long-Horizon、Memory、Open 五个维度报告 Score / 完整成功率，并取三个 seed 平均。LAW 的平均为 6.47 / 3.82%，Fast-WAM 为 3.48 / 2.03%；长程为 11.16 / 6.67%，记忆为 7.46 / 5.44%，Open 仅 1.53 / 1.00%。在作者列出的无额外具身预训练方法组中，LAW 各维度领先；但具身预训练的 X-WAM 平均 Score 为 7.69，平均成功率为 3.83%，长程成功率为 9.08%。[表3]

所以更稳妥的判断是：框架在困难任务里改善了进度和部分成功，而可靠开放世界操作距离很远。也不能用 RoboTwin 的 94.21% 为 RoboDojo 的广泛能力背书，两者任务难度、训练分布和评价范围明显不同。

专用 2B 优于大 VLM，实验具体比了什么

表7固定 WAM 和其他执行设置，三种 VLM 的value-guided fusion 全部关闭，只比较剩余子任务规划和完成评估。LAW VLM 达到 93.80%，Embodied-R1.5 为 88.8%，GPT-5.5 High 为 88.7%。这支持任务专门训练、角色分离的 2B 模型能更有效地对接这套机器人控制接口，不能外推成“2B 的通用推理能力超过大模型”，也不能说 value 模块击败了 GPT。替代模型是否具备同等监督适配与提示优化，论文没有给出充分对齐细节。[§5.2、表7]

表4进一步显示，hybrid experts、失败负例和记忆逐步加入后，完成判断准确率从 85.78% 到 99.02%，召回率从 67.27% 到 97.13%；图8误报率从 11.4% 到 0.7%，漏报率从 32.7% 到 2.9%。剩余计划 exact match 为 99.64%，纯文本“指令＋已完成任务”基线为 70.10%。这说明视觉状态与专门化确有帮助，但测试仍是已知任务模板中的未见随机场景，不能据此认定开放任务分解已解决。

哪些结论还不能顺着标题外推

局部完成的标签，依赖语义标注与运动代理

附录C不是直接从物体是否正确落位计算所有 completion 标签。作者先给定语义阶段区间，再累计位置、旋转、夹爪变化；各分量按该区间总变化归一化，过滤近静止分量后等权平均，取末尾连续满足进度 ≥ 0.995 的帧作为完成区。没有可用运动量时退回时间插值。14 维关节轨迹还使用关节运动代理，而非严格笛卡尔运动。[附录C]

作者明确说这只是端点容差，并非任务无关的物理成功标准。它能提供稳定的监督位置；但“机器人动作几乎走完”与“物体确实正确放好”并不等价。因此 99.02% 的完成分类准确率首先说明模型拟合该标注体系有效。要验证真实接触失败、物体滑落或反复重试时的完成判断，还需独立的物体状态真值与部署误切换统计。这是需要检验的外推边界，不能直接断言现有 detector 无效。

给候选打分，并不自动保证它们的均值安全有效

Value 训练只看记录动作，部署却评估 WAM 的随机候选。两种骨干上的收益提供了经验支持，但未报告候选分布上的校准误差、排序准确率或不确定性。合成失败主要来自漏抓、提前释放、错误放置、漏接触和错位操作；每任务选 1–3 种模式，再过滤无效或模糊样本，不能代表全部开放环境失败。

更关键的是，真正执行的是 top-8 的融合结果，而不是其中某个已评分候选。如果高分轨迹分别从障碍物两侧绕行，它们的均值可能穿过障碍物；夹爪平均也可能落在不同开闭意图之间。这是动作分布多峰时的潜在风险，本文未报告它已造成的失败比例，也没有在算法中对融合结果再次评分或做显式约束验证。可澄清的实验应比较 top-1、无评分平均、top-K 融合及融合后复检，并固定候选数和推理预算。

还有一个可直接从公式推出的性质：Q 是 [−0.01, 1.01] 上的分类期望，T = 1 时任意两个候选的未归一化权重比最多为 e1.02 ≈ 2.77。即便 top-8 中一个在上界、其余都在下界，最高权重也约为 28.4%。这意味着默认融合不是接近硬选择，top-K 截断本身可能承担很大作用。该上界是本页按公式计算，不能代替作者未报告的温度、K 与融合策略消融。

局部价值可能遗漏跨阶段后果

在子任务边界切断回报能保留失败前缀，这是本文设计的优点；代价是 value 不直接惩罚“当前子任务完成了，却让下一步更难”的动作。例如完成放置，但位置不利于后续抓取。全局指令、planner 与闭环观测可以部分补偿，但本文没有比较纯局部 value 与局部—全局混合目标，也没有提供跨阶段代价的专门测试。因此该选择更适合语义阶段与后续可行性相对一致的任务。

运行代价和泛化范围仍需补证

论文报告 state 的约 60 ms 与 15% 吞吐提升，却未给出可完整重建的端到端延迟表、32 候选的评估成本、不同历史长度下的开销和相同硬件下的整体控制频率。不能把 60 ms 当作 LAW 的一次完整决策延迟。记忆保留的边界数量还会随任务推进增加，长到何处仍能维持吞吐需要额外测试。

对泛化也应分别看：已有随机化场景和两个 WAM 骨干验证值得承认；任务定义、语义拆分和完成监督仍较强，真机仅三个任务、固定相机和单平台。更有针对性的下一步是未见子任务组合、遮挡与状态歧义、可恢复失败注入、固定 token 预算的记忆对照，以及完整耗时分解。论文结论也把跨机器人形态与自适应子任务分解列为未来工作。

这篇论文最值得带走的设计原则：以一个可检测、可评估的语义目标作为模块间接口，并让完成事件同时更新动作条件、价值终点和记忆保留策略。MoTE 是对动作骨干的增强；真正将整套系统组织起来的是“语义进度驱动控制”。现有结果足以支持这一工程与建模方向，但还需要更开放任务和真实失败恢复实验来检验它能走多远。
