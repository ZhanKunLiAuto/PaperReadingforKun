VISUAL MEMORY · MODEL-DIRECTED INSPECTION

VISTA

让模型在需要时重新看见证据，而不必第一次就记住所有细节。

Qiushi Han、Keya Hu、Linlu Qiu、Cathy Wu、Kaiming HeMIT · arXiv v1 · 23 页
研究目的

让现有多模态模型在陌生视觉游戏中持续发现规则、纠正判断并规划，减少长程交互中的视觉信息遗失。

核心判断：VISTA 的贡献是把原始画面与有限上下文分开保存，再让模型按问题主动回看。它用机械工具层释放现有模型能力，无须训练新模型或合成可执行世界模型。最有说服力的证据来自同模型逐步增强接口的消融；公开游戏上的满分支持系统有效，还不能证明未知世界中的通用智能。[§3、图5]

Harness 保存证据，模型负责判断

Harness 是连接模型与环境的执行和反馈层。VISTA 接收工具请求、存图、裁剪并返回结果，没有额外训练的感知或推理模型。“无损”指保留环境返回的原始帧，包括动画中间帧；它不保证模型的视觉编码或判断无损，也不能恢复环境从未返回的画面。[§3.1–3.2]

第一次看图时，不知道以后要问什么

某个小色块现在似乎无关，之后却可能决定角色朝向或隐藏规则。图像只编码一次、旧轮次被截断或换成文字摘要后，这种证据可能消失。单纯加长上下文也会增加成本。VISTA 将“现在用于推理的输入”与“以后还能重新取出的证据”分离，避免让摘要承担全部记忆。[§3]

一次动作后，可以先回看，再行动

每轮先看到当前图和可用动作。模型可调用 inspect，指定任意历史轮次、帧号及矩形区域，比较前后状态或放大局部；需要精确颜色时用 read_pixels 获取数值。它先提出预期，再用 play 执行一个环境动作，所有返回帧自动归档，最后一帧成为下轮观察。检查可以多次进行，不推进游戏。[图3、附录A.4]

交互图解 · 上下文压缩后，原始证据还在哪里？

文字记忆另有分工：GUIDE.md 保存跨关卡规则，WORKING.md 保存当前状态和计划。上下文接近上限时，模型写交接摘要，在新上下文中继续，笔记、动作历史与图像档案仍在。作者称之为对历史的“显式注意力”：这是模型选择工具和证据的行为，不是新增 Transformer 注意力层。[§3.2、附录A.4]

图5全部使用 GPT-5.6 Sol、max 推理与相同 CLI 接口。无损记忆与检查这一步提高 24.05 个分数点，但同时将每动作自动返回最多七帧改成只返回最后帧、其余按需取回；不能把收益单独归给“多存图”。低通关配置的动作数少也可能只是早停。官方 13.33 是 API 外部参考；Opus 官方 high 的 40.68 与 VISTA xhigh 的 100.00 也非只改接口的受控比较。[图5、附录A.1–A.2]

满分有明确范围。Opus 5.0 通关 25 个公开游戏，RHAE 100.00，总动作 7,302，对应人类参考 17,135，少 57.4%。RHAE 将动作效率与通关比例结合，较后关卡权重更高，单游戏最终封顶 100；它不衡量推理耗时，也不是每一步都正确。GPT 的三次运行为 99.04 ± 0.17，支持结果稳定；该重复统计不能套给 Opus。[表1–2、附录A.3、B.1]

收益不限于一种游戏。同一 GPT 骨干在 GameWorld 的 170 项任务上成功率从 40.0% 到 63.3%；AI GameStore 的 10 款游戏人类归一化几何均值从 47.3 到 140.3（人类中位数为100）；BabyVision 仅测 39 道视觉追踪题，准确率从 41.0% 到 63.2%，仍低于人类参考 92.3%。静态题没有历史记忆需求，这里支持的是局部检查的价值。[图11、§5；附录B.1]

动作省了，计算并没有免费

公开题目与模型能力的边界。作者承认模型发布晚于公开评测，无法排除训练数据包含游戏；未报告 ARC 私有集。开放权重 GLM-5.3 Flash 320B 从去掉检查工具时的 13.27 升到 66.93，但仍远低于闭源骨干，说明接口收益并未消除模型差距。[§6、图8]

免费检查只指动作计数。ARC 预算提高至每游戏 2,000 动作、48 小时；人类参考研究每游戏硬上限30分钟。默认 GPT 200K 上下文平均每游戏消耗 30.7M tokens；100K 降到17.3M，RHAE仍有98.6，780K反而为93.9、105.7M tokens。结果支持按需取回优于盲目加长窗口，却不足以证明整体时间或金钱效率超过人类。[图7、附录A.2、A.6]

视觉复杂度仍影响可靠性。同一 ARC 游戏改成3D渲染后，RHAE从99.00降到84.12，动作从9,126增到20,640。这是渲染变化的压力测试，不能替代真实机器人或开放物理世界验证。本页判断：最值得迁移的是“摘要保存判断，原图保存可复查证据”的记忆设计；长期海量画面的存储与检索管理仍需额外验证。[图9、§7]
