WORLD MODELS · EVIDENCE & MECHANISMS

State World Models

先决定世界发生什么，再让视频模型把它画出来

Chan Yan Ki 等2026-10-19 · arXiv v1

总体判断：本文最有价值的贡献，是把“世界应当发生什么”从视频生成中拆出来，让可执行规则和显式状态先结算事件，再要求冻结的视频模型忠实表现事件。它不是训练出了一套新的物理动力学，而是把现成视频模型组织为受规则约束的交互世界。50 对同画面、同动作、不同隐藏状态的测试中，同一 MiniMax-H3 从规则提示的 32% 成对结局正确率，上升到显式结局提示的 64%，再到 harness 的 92%；严格排除禁用结局时达到 90%。这有力支持显式结算与编译的系统价值，但还不能把它理解为任意现实物理规律、长程视觉记忆或实时模拟已经解决。[§3–5，表1、4]

全篇要抓住两条不同的正确性链：规则程序决定合法状态转移，视频模型负责把转移画出来。前者可以用类型和检查器约束，后者仍然会出错。视频反馈可以补充合法细节，却没有权力把“不许打开的门”改写成已经合法打开。把两者分离，才使错误能定位到规则、编译还是渲染。

隐藏状态为什么不能只靠上一帧

论文以宝箱为例：两张画面完全相同，用户都选择开箱；一个角色持有钥匙，另一个没有，正确结局分别是打开与保持锁定。钥匙是否在背包里不是图像必然包含的信息。如果只保存最后一帧并让视频模型继续生成，模型既没有可靠的状态账本，也没有必须遵守的状态转移约束。[图2]

作者将状态写为 sₜ=(zₜ,uₜ)。z 是语义账本，保存资源、属性、任务进度、态度、终止状态；u 是可编辑的空间状态，保存实体布局、尺度和相机路径。固定规则 R 读取二者与动作 a，给出允许的事件。这里的“world model”是包含执行程序和渲染器的整体系统，不等于视频网络本身学会了全部规则。

空间状态采用 clay model：由初始图像恢复粗略几何，用地面和带标签的长方体表达对象。它提供的是布局与相机运动参考，并非高保真物理重建或可直接当真值的网格。语义账本补足盒子表达不了的钥匙、好感度、法力等变量；图像锚点则维持外观。三种表示各有职责，不能互相替代。

从可导航到规则一致，还差哪一步

相机移动顺畅、人物出现动作、结尾看起来合理，并不保证不同隐藏条件会导致不同合法结果。若两段视频最后都开箱，单看其中一段可能成功；成对检查才能发现忽视隐藏状态。因此本文没有仅以画质或单片段动作响应来定义世界模型能力，而是明确提出 Change-to-Comply：先有可辨认事件，再检查它是否服从规则。[§4]

既有视频生成器可接受动作文本、首帧和参考视频，作者复用这些标准接口并冻结权重。新增部分主要是类型化世界定义、规则结算、VisualScript 编译、可编辑场景和受规则约束的反馈接入；这是系统组合贡献。论文声称新游戏可通过新定义文件接入，“training-free”指不微调视频权重，不表示没有代码生成、初始几何恢复、提示设计和推理成本。

一个回合如何执行、渲染和写回

阶段 0：固定规则，初始化可变状态

编码 agent 从世界描述生成小型类型化程序，声明状态 schema、动作、guard（触发条件）、effect（状态与空间修改）、事件和目标。定义在交互前验证并冻结，后续变化的是账本和场景。反事实双胞胎共享同一规则和首帧，仅改变指定隐藏变量；这样差异可以明确归因于状态而非换了场景。[§3.1]

先结算，再把结果编译成模型能执行的条件

给定 sₜ 和 aₜ，τR 先得到临时语义状态 z̄ₜ₊₁、空间编辑 εₜ 和事件 eₜ；apply(uₜ,εₜ) 得到临时布局。VisualScript 将 actor、action、target、reaction、dialogue、effects、endstate、shots 等槽位确定性编译为文本。可选神经组件只在合法事件集合内提出对白等表达，通过 schema 检查、截断、有限重试和默认值回退，不能改写已结算的分支。[式2–3]

更新后的 clay model 可渲染空间预览；文本负责语义结果，预览负责几何及镜头，上一片段末帧负责外观连续性。视频网络 Vθ 接收这些条件后生成新片段，权重 θ 不变。预览必须被明确称为布局参考，否则视频模型可能把黏土外观也复制到最终画面。[式4；表8]

切换同一动作的两条规则分支与反馈阶段，观察图中新增或改变的处理环节。宝箱是原文图2的机制示意；不模拟真实生成成功率。

视频是观测来源，却不是规则裁判。生成出的非法开门不会使本来非法的事件变成合法。

反馈的作用与权力边界

Oψ 查看新片段、临时状态和事件，提出可见语义或空间变化；UR 只接纳合法更新，形成 sₜ₊₁=UR(s̄ₜ₊₁,Oψ(vₜ₊₁,s̄ₜ₊₁,eₜ))。末帧另作为下一轮视觉锚点。因此系统确有视频反馈闭环，但“画面与账本矛盾”不会自动被修复为正确画面；程序只能拒绝非法账本更新，渲染不一致仍须被评测记录。[§3.2，式5]

92% 到底证明了什么

成对成功与严格成功是不同指标

WorldState-Bench 包含 50 对、100 个片段、49 个隐藏变量、21 个主题。每对只改变隐藏值；初始图像经过审计以减少泄露。ENDFOLLOW 检查规定结局是否出现；PAIRFOLLOW 要求一对都成功；STRICT 还要求禁用结局全程未出现；PAIRSTRICT 再要求两段都严格成功。UNCLEAR 不计成功。只没有禁用内容，可能是视频根本没发生事件。[§4，附录A–B]

自动评审有人工核验，但仍有取样误差

Qwen3.8-27B-VL 以 3 fps 加末帧回答固定选项问题，看到期望结局，不看到隐藏值与规则文本。102 个片段的盲审中，每段三名人工评级，VLM 对正确结局与禁用内容的问题分别与多数人一致 91.2%、86.3%。另有 25 对场景、四个对手的盲选偏好，harness 在聚合判定中赢 98%，另 2% 为两位审查者分歧。这个 98% 是规则遵从偏好，不能改写成总体画质胜率或 98% 世界模型成功率。[附录C，表3]

外部基准与长程演示分别说明什么

WBench 中，完整配置的 setting adherence 为 87.2、interaction 为 77.7、physical plausibility 为 68.8；一致性为 77.8，低于原始文本协议的 83.8。通道改动并非各项都改善，预览可能带入外观干扰。三个真实 harness 演示分别持续 15、29、11 回合，涵盖探索、叙事与战斗，证明同一框架能运行多回合与不同规则；没有对大量长回合 episode 的失败率、漂移和延迟给出对应系统统计。[表2、8；图6、15–17]

哪些结论仍需额外验证

规则来源决定适用范围。评测期望结果与 harness 执行都来自同一程序，测试的是已定义规则的可视化遵从，不是从经验发现规则是否符合真实世界。作者透明披露了这一点；研究可迁移到规则明确的交互生成，若用于物理预测，仍需独立环境真值、接触约束和错误规则压力测试。

文本改写与执行的贡献尚未完全拆开。32→64→92 的阶梯很重要，但后半段把多个组件一起加入。更严格的归因可保持同一终态描述、同一参考条件和 token 预算，分别去掉执行器与编译器，再看违规事件如何变化。这是本页建议，非作者已经完成的实验。

账本一致不保证画面一致。规则能防止非法观测污染账本，却不能证明所有可见小事件都正确，也不能恢复错误生成造成的视觉锚点漂移。3 fps 判定可能漏掉短暂违例，单次生成与少量世界模板也限制方差估计。长回合应同时测账本真值、可见状态、跨帧身份和错误恢复，才能判断闭环累计误差。

最值得借鉴的是明确分配权力：确定性程序负责必须可靠的约束，生成器负责开放表达，视觉回读负责有限且可审计的更新。这里的优势来自接口设计与错误隔离；“冻结模型”并不意味着系统端到端可靠，也没有实时性测量可以支持游戏引擎级帧率。
