PHYSICAL LANGUAGE · REASON THEN RENDER · OPEN-WORLD VIDEO

PhiZero

一篇试图把“下一段视频长什么样”改写成“世界发生了什么变化”的论文：先把状态过渡压缩成离散符号序列，再让 VLM 在这个过渡空间里推理，最后交给扩散模型渲染。

Shuyao Shang 等 7 位作者 中国科学院自动化研究所等 arXiv v1 · 25 页
研究目的

把直接在高维像素空间里隐式预测世界动态，变成先在紧凑、离散、可自回归建模的“物理语言”里显式预测状态过渡，再利用预训练视频扩散先验补回外观细节；目标是获得更物理一致、可控、可迁移的开放域世界模型。

核心结论

第一，“物理语言”不是牛顿定律的符号化版本。它是从视频重建任务里自监督学出的离散状态过渡码；论文明确承认这些码尚未对齐可解释物理变量或形式定律。

第二，reason-then-render 的成立依赖一个精心设计的信息瓶颈。邻帧 Q-Former 抓局部过渡，FSQ 将其离散化，首帧提供静态外观，预训练扩散模型补细节，pure-noise warm-up 又迫使解码器真正使用过渡条件。

第三，最强的实验证据是多类物理生成基准和结构消融；最弱的外推是“零样本迁移等于可执行控制”。跨人—机器人形态与 sim-to-real 展示证明视频过渡可重渲染，还没有证明机器人策略能照着这些视频稳定执行。

READING OBJECT

“物理语言”有三个限定：离散、经验性、描述状态过渡

PHYSICAL LANGUAGE（物理语言）

英译中：对视频中世界状态变化模式的紧凑离散编码。

怎么理解：33 帧四秒视频经 VAE 得到 9 个时间状态；相邻 8 个区间各抽取 32 个符号，总计 256 个 token。它类似“变化词汇”，但每个词当前没有人类可读定义。

REASON-THEN-RENDER（先推理、后渲染）

英译中：先预测未来怎样变化，再把变化渲染成视频。

怎么理解：Qwen3-VL-4B 根据首帧和高层动作意图，自回归输出 physical-language sequence；Wan2.2-5B 扩散解码器再以首帧与这些 token 为条件生成未来。动态推理与像素合成被分成两个概率因子。

FINITE SCALAR QUANTIZATION（有限标量量化）

英译中：把低维连续特征的每个标量压到有限等级，并用等级笛卡尔积形成离散词表。

怎么理解：配置 (8, 5, 5, 5, 5, 5) 产生 25K 个可能符号，不需要单独学习 VQ codebook；优势是离散稳定，代价是符号语义由组合坐标隐式形成。

WHY PIXEL-FIRST IS NOT ENOUGH

旧方法的问题不是不会画，而是“变化规律”没有独立成为预测对象

MECHANISM

Tokenizer 学“变化词典”，Reasoner 学“怎样写下一句变化”

公式拆解 · 为什么叫 reason-then-render
p(V, z | I0, c) = p(z | I0, c) · p(V | I0, z)

这条公式回答：未来视频生成怎样被拆成“预测状态过渡”与“按过渡渲染画面”两个可分别训练的任务。

I0
第一帧，既是当前世界状态，也直接提供静态外观。
c
高层动作或交互意图；训练 caption 被刻意限制为不泄露完整结果。
z
离散 physical-language sequence，描述从首帧到未来视频的状态过渡。
V
目标未来视频；解码器根据 I0 和 z 恢复。
直觉读法：Reasoner 先回答“接下来发生哪种变化”，Decoder 再回答“这种变化在当前物体、材质与背景里看起来怎样”。如果 z 能跨外观复用，就说明两个因子至少部分解耦。

数据课程把短时变化、长时变化与高分辨率渲染分开学

Tokenizer 预训练从约 50K 小时池中筛出 10K 小时视频，按 1 秒、2 秒、4 秒逐步增加时长，再把输出分辨率从 256×448 提到 512×896。随后用 5M 个四秒真实/仿真 clip 做 SFT。Reasoner 先在同一 5M clip 上继续预训练，再用 800K 高运动质量样本与 200K 仿真样本做运动聚焦 SFT。

结构消融

生成先验最关键

去掉扩散解码器，PSNR 28.9 → 26.6，是 Tokenizer 消融里最大下降，支持“瓶颈省略外观、先验补细节”的分工。

Reasoner 消融

自然语言提示不够

Wan2.2-5B 从 21.2 经 prompt enhancement 到 26.6，仍远低于完整模型 41.2；去仿真数据为 37.7，改单阶段训练为 39.2。

表征分析

过渡码有运动结构

驾驶转向与机器人夹爪动作在 PCA+UMAP 后形成流形或簇，但这是选定四类、每类 300 个样本的可视化，不是全词表可解释性证明。

TECHNICAL DEBT & BOUNDARIES

它发明了可推理的过渡码，还没有得到可解释的物理定律

证据较强

离散瓶颈能保留有用动态

256 个符号在高压缩重建、生成基准、理解似然和跨外观重渲染上都有正证据，且关键组件消融方向一致。

只能有限外推

“物理”来自视觉经验

模型学习训练视频里的经验规律，不显式满足守恒、接触或材料方程；数据偏差和视觉歧义会直接限制覆盖。

仍待验证

长时、交互式闭环稳定性

主模型固定生成四秒 clip；顺序控制展示说明可递推，但没有系统量化多段 rollout 的状态漂移与误差累积。

符号还不能直接翻译成力、质量或接触

论文附录明确写道：physical language 是经验状态过渡表征，不是符号物理定律。25K 个 FSQ index 的组合坐标没有对齐人类可解释变量，因此“显式推理”指模型显式预测中间序列，不等于人类能读懂推理链。

纯视觉无法覆盖触觉与不可见动力学

材料内部状态、微观粒子、摩擦系数、触觉接触和遮挡后的力学结果，可能产生相同或相似像素却需要不同预测。作者把触觉与微观动态列为现有覆盖盲区。

计算规模仍然高，且没有完整成本对照

Tokenizer 与 Reasoner 的多个阶段都使用 128 张 A100；总数据包括 10K 小时预训练视频、5M SFT clip 和 1M 运动聚焦 clip。论文没有给出总 GPU 小时、推理吞吐或相对直接视频模型的端到端成本。

理解评测依赖模型自身似然，生成评测含 VLM 裁判

IntPhys2、LikePhys 与 YoCausal 通过比较两段视频对应 physical-language sequence 的 Reasoner 对数似然来判别；PhyGround 与 WorldModelBench 又使用专用 VLM judge。结果支持内部一致性，但仍需要更广的人类物理判断、真实测量和独立 evaluator 校准。

跨形态迁移是视频层演示，不是策略层验证

把人体动作迁到 G1、把人手迁到 Sharpa dexterous hand，做法是保留过渡 z、编辑首帧后重渲染。目标视频可能视觉连贯，却没有机器人动作、控制器、碰撞或成功率评测；“零样本 motion transfer”应按这一范围理解。
