EvoLife · Ask to Evolve

把问路、几何行动和可持久记忆放进同一导航系统

Kai Sheng 等 · 29 页2026-10-29 · 用户提供的 PDF 版本

EvoLife 的价值，是把“不会走时问路、走过后记住、下次少问”实现成统一的导航流程。系统同时支持局部移动、几何路点、画面目标点和对象目标，再把观察到的地图、地点、路线与对话保存下来。论文中，从首次访问到带记忆再访，成功率和路径效率都有明确收益；真实机器人案例也展示了跨天恢复导航状态的可行性。

解释这些结果时，最重要的条件是：首次访问可以询问一个知道目标位置、地图和参考路线的向导。主实验中的向导是独立模型，拥有导航器看不到的特权信息。100% 的成功率因此是“导航、几何工具和有信息优势的交互帮助”组成的系统结果，不是纯视觉导航模型在未知环境里独立解决所有任务。记忆再访关闭问询，验证的则是同一任务经历能够被复用。

系统里到底有哪些信息

导航器接收四向 RGB、由深度观测形成的局部几何、模拟器当前位姿，以及任务文本；初始没有预建地图。它可以调用感知、移动、记忆与询问工具。向导另外知道当前及目标位置、最短路径、地图、参考路线图像或目标实例等信息，通过自然语言回答澄清、方向或到达确认问题。每个子任务最多 10 次交互。

“地图未知”与“没有定位信息”不是同一个条件：这里导航器可使用当前位姿，并逐步累积观察到的自由空间。“终身”也不意味着在权重上持续学习；演化的是结构化记录与可执行的导航上下文，基础模型参数不更新。

目标成功要求随基准不同：R2R / RxR 需停止在距目标 3 米内；HM3Dv2 的对应视点要求更严格，阈值为 0.1 米；OVON、VLLN、CoIN 和 GOAT 使用 0.25 米；LHPR 点目标为 1 米。SR 要求在正确位置 STOP，OSR 只要求途中曾到过；SPL 同时考虑成功与路线长度，连续任务的 episode SR 则要求全序列成功。跨基准相同的“100%”不能理解成同样难度的几何控制。

为什么仅有离散动作或单一地图还不够

导航遇到的困难来自不同层次：不知道用户指的是哪个物体，需要语义澄清；知道大致方向却看不到可通行路线，需要几何推理；已经看见目标但还没进入成功半径，需要近距离控制。用一种“向前走一步”的接口解决所有问题，会让高层模型反复处理低层细节；只给一个“走到目标”的接口，又会掩盖定位误差和执行失败。

EvoLife 选择让模型根据当前问题使用不同粒度动作，并在路线中途主动收回控制。问询补充缺失的语义和位置线索，几何模块把意图变成可执行路点，记忆让已经验证的地点可以再次被定位。三者形成互补：问来的信息若不保存，下次还要问；只保存文字而没有位置和历史视角，也难以稳定返回。

需要注意，向导能回答“你是否到了”就承担了部分目标验证功能。系统的成功并不只由导航器的自我判断产生，尤其在小成功半径任务中，最后几轮纠正可能决定是否达标。论文对到达确认做了专门干预，这比只报总成功率更能说明交互帮助的实际作用。

机制：混合动作连接可查询记忆

切换查看首次访问、四类动作和再访流程。向导的特权信息只以回答形式传给导航器，但仍属于系统的重要外部输入。

首次访问与询问

任务 + 四向 RGB + 位姿 / 深度几何
→
导航器发现语义或方向不确定
→
向导：目标 / 地图 / 路线信息
→
语言回答 → 继续导航

问题可以是澄清对象、询问路线或确认到达。这个外部信息通道必须计入实验条件，不能只把它看作模型自我反思。

选择动作粒度

候选路点 / 0.25 m 步进 / 图像点 / 对象
→
几何投影 + 可达性检查
→
局部路径与机器人执行
→
距离 / 时间 / 碰撞等条件触发返回

不同动作最终都需要几何后端执行。高层可以设置途中检查点，让长距离移动变成可观察、可中断的过程。

记录与再访

几何 + 地点 + 路线 + 对话
→
按名称 / 描述 / 对象检索地点
→
检查带历史标识的图像和记录
→
从当前位置重新规划到旧地点

再访不是机械回放当年的动作序列。导航器使用保存的地方信息，从当前状态重新规划；绕路后可以恢复原目标。

四类动作的语义不同

候选路点来自已观察几何中的可达位置；离散动作按 0.25 米平移、15 度旋转；图像点动作接收归一化画面坐标，利用对应图像版本的 RGB-D 和相机变换投影到地面，再检查是否可达；对象动作把对象标识转换成附近自由空间中的停靠位置，而非直接撞向物体中心。对象定位可结合边界框或点提示，使用深度连通性和重投影检查。

行动工具可以按距离或时间主动返回，也会因碰撞、无进展或执行预算中断。因此模型不仅选择“去哪里”，还选择“多久以后再看一次”。不过底层仍是几何规划器与控制器，不能把这些结果解读为多模态语言模型直接学会了连续运动控制。

记忆的单位是可追溯地点，不是一段无限加长的对话

记忆包含已观察几何、地点、路线和对话。地点记录有唯一标识、实际位姿、名称与描述、相关对象、历史四向图像、对话与地图上下文、时间以及 active / retired 状态。几何、路线和对话由系统自动积累；语义地点记录由模型选择维护。检索主要依据名称、描述和对象标签，历史图像带有历史标识，避免与当前画面混淆。

选择旧地点后，系统从当前位置通过已观察几何重新规划，不原样重放旧路径；路线执行被打断后还可恢复目标。这一设计让记忆能支持“临时绕到门边，再继续去原房间”，但记录仍可能陈旧，需要当前感知核验。论文没有证明这种记忆在长期环境变化下总能保持一致。

模型配置与状态隔离

主要配置的导航器和向导都使用 GPT-6 Astra ultra；替换模型实验同时替换两者，另测 Qwen3.8-Max 与 DeepSeek-V4.1-Flash。因此性能差异不是只改变导航器的纯消融。新任务序列会重置状态，同一序列的子任务保留记忆；再访实验读取对应首次访问所形成的记忆，同时禁用向导。

证据：高成功率、交互依赖与再访收益

评估包含六个单任务设置各 100 个 episode，加上 50 个 LHPR 长过程 episode 与 50 个 GOAT episode，总计 700 个完整 episode、1,105 个子任务。R2R 使用固定子集，其余若干设置随机抽样；LHPR 与 GOAT 在抽样前排除了标注不满足协议的部分样本，因此这些结果不等同于完整排行榜评估。

最后一次“到了吗”有多重要

作者让系统在首次提出到达确认相关问题时立即 STOP，保留此前问答。SR 在 R2R / RxR / OVON / HM3Dv2 分别降为 90% / 95% / 69% / 89%。这说明晚期纠正对完整系统的高成功率很重要，尤其是严格距离阈值的对象任务。但该干预既移除了回答又提前终止行动，并非只拿掉一条信息而保持后续策略完全相同；因此不能把下降全部解释成该回答单独的因果贡献。

论文描述的 GOAT 失败很具体：系统和向导找到了正确书柜，但停在 0.73 米处，未满足 0.25 米阈值。几何控制器说“已到路点”、语义上“找到物体”和评测判定“成功停止”是三件不同的事。这个例子也说明，目标识别正确后仍有独立的行动校准问题。

资源和真实机器人证据

R2R 的导航器活跃时间从首次访问约 164.08 秒降到再访 107.41 秒；这不是包含向导、所有系统服务与现实等待的统一端到端成本。真实实验展示同一环境两天内的三项连续任务，包括约 87 米到电梯、记忆返回和次日约 60 米到玻璃办公室，遇到关门时请求人帮助开门。这证明流程能够接入实机并恢复记忆，但样本量和场景覆盖不足以支持普遍长期可靠性。

边界：帮助、记忆与自主能力要分别衡量

EvoLife 最强的结果需要一个可靠而有信息优势的向导。现实人类未必知道最短路、目标坐标或精确距离，也可能回复含糊、延迟或错误。当前实验没有充分量化错误向导、过时地点、动态障碍和定位漂移组合出现时的表现，因此“100%”必须连同帮助条件一起引用。

四类动作、几何后端、语义记忆和交互都在完整系统中同时起作用；已有对照很好地揭示交互与再访价值，却没有将每种动作接口的独立贡献全部拆开。进一步实验应固定交互信息预算和向导能力，测量没有目标坐标帮助时的收益，区分记忆中的几何、图像、语言与历史向导信息，并在新布局和跨时间变化中评估错误恢复。

我的总体判断是：它提供了一套有价值的长期导航组织方法，尤其强调经验要可检索、可定位、可执行。真正可迁移的设计不是某个惊人的成功率，而是把“不确定就问、执行后核验、验证过的地点才进入可复用记忆”变成显式工具与状态。至于在怎样的帮助预算下能达到多强的自主能力，仍需要更严格的分层评估。
